# 사전 등록 — 재현성 (3장 정의)

**결과를 보기 전에 고정한다.** 판정 기준을 결과에 맞춰 고치면 그 순간 근거가
아니게 된다. 이 문서는 측정 코드보다 **먼저** 커밋한다.

작성: 2026-09-09 · 미결 `ho` 34번 · 3장 「검증 기준」

## 1. 무엇을 묻나

제안서 3장이 내건 지표다.

> | 재현성 | **동일 영상 5회 반복** 시 총점 표준편차 | 3점 이내 |

**이 정의로는 아직 잰 적이 없다.** 6장의 *"재현성은 실측으로 확인됐다 —
표준편차 0.00"* 은 **동일 측정값으로 판정만 3회** 반복한 것이라 영상→포즈→지표
구간이 빠져 있다. 6장은 조건을 정확히 적어 두었으므로 6장이 틀린 것이 아니라
**두 문서가 다른 것을 재현성이라 부른다.**

## 2. 🔴 판정 모델을 돌리지 않는다 — 그리고 그것이 왜 정당한가

**총점은 등급의 가중합이고, 등급은 코드가 정한다.**
`judge.py` 가 `grade = criterion.grade_for(features)` 로 받아 오고(342행) 모델은
근거 문장만 쓴다. **그래서 모델의 출력이 총점을 바꿀 수 없다.**

따라서 이 측정은 **영상 → 포즈 → 지표 → 등급 → 총점** 구간만 반복한다.
LLM 을 5회 × N클립 돌리는 시간을 아끼려는 것이 아니라, **그 구간이 총점의
분산원이 아니기 때문**이다.

🔴 **이 전제 자체를 검사로 고정한다.** 전제가 틀리면 이 측정의 범위가 틀린
것이므로, 아래 기준 E 로 함께 판정한다. 나중에 누가 등급을 모델로 되돌리면
그때 이 측정도 무효가 된다는 것을 남긴다.

## 3. 표본

| | |
|---|---|
| 클립 | 축구 인스텝 슈팅 **3편** (`10_penalty1` · `11_freekick` · `12_penalty`) + 농구 점프슛 **1편**(`bball_shot.mp4`) |
| 반복 | 클립마다 **5회** (3장 정의 그대로) |
| 왜 축구인가 | 지금 `features_ok` 표본이 있는 유일한 active 루브릭이다(18편). 야구 투구는 가진 클립이 품질 게이트에 걸려 0편이다 |
| 왜 프로세스를 새로 띄우나 | 같은 프로세스에서 5회 돌리면 캐시·전역 상태가 회차 간에 남아 **실제보다 재현성이 좋게 나온다**. 회차마다 새 프로세스로 돈다 |

## 4. 합격 기준 — 결과를 보기 전에 고정한다

| | 기준 | 합격선 |
|---|---|---|
| **A** | 총점 표준편차 | **≤ 3.0점** (3장 목표 그대로) · 클립마다 |
| **B** | 등급 벡터가 5회 전부 동일 | 클립마다 5/5 |
| **C** | `features` 값이 5회 전부 **비트 동일** | 클립마다 5/5 |
| **D** | 5회 중 **품질 게이트 결과가 갈리지 않는다** | 같은 영상이 어떤 회차는 되고 어떤 회차는 안 되면 **재현성 없음**으로 본다 |
| **E** | 등급이 모델과 무관하다 | `judge_criterion` 이 `grade_for` 로 등급을 받는다(2절 전제) |

**A 와 C 를 함께 두는 이유**: A 만 보면 「이번에는 같았다」밖에 못 말한다.
C 가 깨졌는데 A 가 통과하면 **지표는 흔들리는데 등급 구간이 넓어 가려진 것**이고,
그것은 다음 클립에서 터진다. **C 불합격은 A 합격으로 상쇄되지 않는다.**

## 5. 예상과, 틀렸을 때 무엇을 뜻하는가

**예상: 전부 합격.** 파이프라인에 난수가 없고 샘플링은 `idx % step == 0` 균등
추출이다. 그리디 디코딩은 총점 경로에 없다.

🔴 **그래도 재는 이유**: GPU 연산은 결정론이 보장되지 않는다(cuDNN 비결정
커널·부동소수 누적 순서). 「없을 것 같다」와 「재 봤다」는 다르다.

| 만약 | 뜻 |
|---|---|
| C 만 깨진다 | 포즈 추출이 회차마다 미세하게 다르다 → 등급 구간이 가려 주고 있을 뿐이다. **경계 근처 클립에서 터진다** |
| B·A 도 깨진다 | 3장 목표 미달. 서비스가 성립하지 않는 종류의 결함이다 |
| D 가 깨진다 | 품질 게이트가 경계에 걸린 것 — 같은 영상이 어떤 날은 분석되고 어떤 날은 반려된다 |

## 6. 하지 않을 것

- 🔴 **결과를 보고 합격선을 옮기지 않는다.** 3점은 3장이 정한 값이다
- 🔴 **표본을 결과를 보고 늘리거나 줄이지 않는다**
- 실패한 회차를 「이상치」로 빼지 않는다 — 재현성 측정에서 이상치는 결과다
- 판정 모델을 돌리지 않는다(2절). 근거 문장의 재현성은 **다른 질문**이고
  여기서 답하지 않는다
