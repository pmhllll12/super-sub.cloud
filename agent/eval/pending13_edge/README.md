# 미결 13번 — `np.gradient` 끝단 단측차분, 실측

[미결 13번](../../../jekyll/pages/pending.markdown)이 "끝단이 오염에 구조적으로
더 취약하다"고 적고 처방 후보 셋을 열어 둔 상태였다. **어느 것도 고르지 않은
채로 무엇이 얼마나 일어나는지만 쟀다.**

```bash
uv run python eval/pending13_edge/measure_edge.py                      # target 30 (/mnt/d)
uv run python eval/pending13_edge/measure_edge.py --cache eval/phaseA/cache   # target 15 (저장소)
```

## 결론 먼저 — 끝단은 문제의 8%다

| | arm_ext_auto | leg_ext_auto |
|---|---:|---:|
| 산출된 클립 | 39 | 39 |
| **임팩트가 유효 구간 끝단** | **3 (8%)** | 1 (3%) |
| **이긴 프레임의 이웃이 오염됨** | **27 (69%)** | 10 (26%) |
| 　그중 끝단이기도 한 것 | 3 | 1 |
| 오염을 빼면 argmax 가 옮겨감 | 26 (67%) | 9 (23%) |
| 경계 규칙이 반려 | 3 | 2 |

**오염이 argmax 를 정한 27건 중 24건은 끝단이 아니다.** 끝단은 희석이 없어 더
아프게 드러날 뿐, 오염 자체는 클립 전체에 퍼져 있다.

target 15(저장소 캐시)에서도 같다 — 끝단 4건(10%), 오염 30건(77%), 이동
29건(74%). **동작점을 바꿔도 비율이 유지된다.**

## 그래서 처방 (a)는 기각된다 — 정답 없이 판정된다

항목의 처방 후보는 셋이었다.

| 후보 | 판정 |
|---|---|
| (a) 끝단 프레임을 임팩트 후보에서 뺀다 | 🔴 **기각.** 3건을 고치고 24건을 남긴다 |
| (b) 끝단에서 이웃의 usable 여부를 본다 | 🔴 **같은 한계.** 끝단만 덮는다 |
| (c) 속도 정의 자체를 바꾼다 | **미결 5번의 A-1 이다** — 정답이 필요하다 |

(a)는 **고친 것처럼 보이지만 거의 아무것도 바꾸지 않는다.** 경계 규칙 반려
3건이 사라져 통과로 바뀌는데, 그 통과가 옳은지는 여전히 알 수 없고, 오염이
argmax 를 정한 나머지 24건은 그대로 조용히 남는다. **드러나던 실패를 감추고
숨은 오류는 남기는 방향**이라 미결 5번이 지켜 온 원칙("조용히 틀린 값을 내는
것보다 드러나게 실패하는 편이 낫다")과 정면으로 어긋난다.

이 판정에는 **정답이 필요 없다.** 몇 건을 덮는지 세기만 하면 되기 때문이다.

## (c)가 A-1 이라는 것도 실측으로 확인된다

오염원(usable 이 아닌데 각도는 유한한 프레임)을 빼고 다시 뽑으면 argmax 가
**중앙값 64프레임** 옮겨간다 (최대 226프레임, 50프레임 초과가 15건).

미결 5번이 A-1 을 되돌린 이유가 "야구 impact 84.3% 이동(중앙 33프레임)의
정당성을 검증할 정답이 없다"는 것이었다. **여기서 독립적으로 같은 크기의
이동이 재현됐다.** 처방 (c)는 A-1 을 다시 켜는 것이고, 되돌린 근거는 그대로
유효하다.

## 재현되는 사례 — 항목이 적은 그대로다

`gg5xRWjw3f8`, arm, target 30:

| | f297 | f298 | f299 |
|---|---:|---:|---:|
| 팔꿈치각 | 15.5 | **1.2** | 83.1 |
| usable | ✗ | **✗** | ✓ |
| `np.gradient` | −5.7 | +33.8 | **+81.9** |

`f299`는 마지막 프레임이라 단측차분이다 — |83.1 − 1.2| = 81.9 가 그대로 속도가
되어 클립 전체 최대로 argmax 를 이긴다. 안쪽이었다면 양옆 평균이라 절반으로
희석됐다.

## 잡음 증폭비

끝단 단측차분과 안쪽 중심차분에 같은 신호를 넣고 표준편차를 비교하면
**중앙값 1.444** (평균 1.536, n=38). 백색잡음 가정의 이론값 2.0 보다 작은 것은
실제 각도 시계열에 상관이 있기 때문이다.

> 항목에 적힌 1.184 와 다르다. **정의가 다르다** — 여기서는 안쪽 프레임 전체에
> 두 공식을 각각 적용해 산포를 비교했다. 어느 쪽이 틀렸다는 뜻이 아니라 같은
> 이름으로 다른 것을 재고 있으니, 인용할 때 정의를 함께 적을 것.

## 🔴 항목의 재현 경로는 낡았다
