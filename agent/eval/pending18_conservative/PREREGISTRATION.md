# 사전 등록 — 보수적 갱신 (미결 18번 처방 3회차)

**작성 2026.09.09 · 정상호 · 코드보다 먼저 고정한다.**

## 앞의 두 회차가 남긴 것

| 회차 | 결과 | 배운 것 |
|---|---|---|
| 1. 재가중 | 불합격 (C 0/3) | 갈아타는 프레임에 **후보가 1개뿐**이라 곱셈은 argmax 를 못 바꾼다. **외양 신호 자체는 갈린다** |
| 2. 거부·재획득 | 불합격 (C 1/3) | 방향은 산다(190 → 49). 막은 것은 **`K = 41`** 이고, 그것을 끌어올린 것은 **정지 히스토그램의 표류**다 |

2회차가 찾은 병목을 그대로 옮겨 적는다:

| | 대가 |
|---|---|
| 히스토그램을 **갱신하면** | 갈아탄 뒤의 외양을 배워 **잘못된 대상에 고착** (1회차가 이래서 껐다) |
| **갱신 안 하면** | 옳게 따라가는 트랙도 닻에서 멀어져 **`K` 를 41까지** 올려야 안 깨진다 (2회차) |

**이번에 시험하는 것은 그 둘 사이다** — **의심스럽지 않을 때만 갱신한다.**
옳게 따라가는 동안엔 표류를 따라가고, 어긋나기 시작하면 갱신을 멈춰
오염을 안 배운다.

## 🔴 먼저 밝힌다 — 같은 시험 표본을 **세 번째** 잰다

시험용 3건은 1·2회차에서 이미 쟀다. **같은 표본을 반복해서 시험하면 우연히
통과할 확률이 올라간다.** 그래서:

- **합격해도 「고쳤다」가 아니다.** 「구현 회차를 열 근거」까지이고, 그
  구현 회차에는 **이 3건에 없던 클립**이 있어야 한다
- 합격/불합격과 무관하게 **이 사실을 결과 문서에 남긴다**

## 바꾸는 것 — 갱신 규칙 하나

2회차 설계를 그대로 두고 **참조 히스토그램의 갱신만** 더한다.

```
매 프레임, 고른 박스의 app 을 잰 뒤
  app >= UPDATE_TAU 이면   ref ← (1-α)·ref + α·hist(현재 박스)
  아니면                    ref 를 그대로 둔다        ← 오염을 안 배우는 자리
```

## 상수 — 새로 생기는 자유도를 **둘로 막는다**

앞 회차 값을 그대로 들고 온다. 새로 정하는 것은 `α` 하나다.

| | 값 | 왜 (결과를 보기 전) |
|---|---|---|
| `TAU` | **0.6** | 1·2회차와 같다 |
| `REACQ_TAU` · `REACQ_K` | **0.6 · 2** | 2회차와 같다 |
| `K` | **보정용 7건에서 같은 규칙으로 유도** | 규칙을 안 바꾼다. 🔴 **값은 달라질 것이다** — 그것이 이 회차의 예측이다 |
| `UPDATE_TAU` | **0.6 (= `TAU`)** | 🔴 **새 값을 만들지 않는다.** 「의심스럽지 않을 때」의 뜻은 이미 `TAU` 가 정했다 |
| `α` | **0.05** | 표류는 **느리다** — 보정용 `O2GSaYqH8JY` 가 0.72 → 0.49 로 가는 데 약 60프레임 걸렸다. 한 프레임이 기준을 끌고 가면 그것대로 갈아타기를 따라가므로, 20프레임 규모로 움직이게 둔다 |

🔴 **`α` 와 `UPDATE_TAU` 를 결과를 보고 바꾸지 않는다.** 바꾸고 싶으면 4회차다.

## 사전 예측 — 맞았는지도 결과에 적는다

**`K` 가 41보다 뚜렷하게 작아질 것이다.** 보수적 갱신이 표류를 흡수하면
깨끗한 클립의 저(低)app 연속 구간이 짧아지기 때문이다.

🔴 **`K` 가 안 줄면 갱신이 표류를 못 잡은 것이고, 그러면 C 가 좋아져도
그 원인은 다른 데 있다.** 예측을 미리 적어 두는 이유가 이것이다.

## 합격 기준 — 2회차와 **같게** 둔다 (비교 가능하게)

| | 기준 |
|---|---|
| **A** | 자동 경로 **비트 동일** — 깨지면 B-2\~B-6 무효. 지켜지면 **B-6 재실행 없음** |
| **B** | 보정용 7건이 **기준선과 동일** (`K` 규칙상 당연히 만족해야 한다 — 구현 버그 검사) |
| **C** | 시험용 3건 중 **2건 이상**에서 「엉뚱한 사람 프레임」(박스가 있고 app < `TAU`) 이 **70% 이상 감소** |
| **D** | 시험용 3건의 **커버리지가 기준선의 50% 이상** — 「전부 거부」가 이기는 길을 막는다 |

🔴 **「엉뚱」의 기준 app 은 갱신되는 `ref` 가 아니라 항상 `닻`으로 잰다.**
갱신되는 기준으로 채점하면 **기준이 답을 따라가서** 어떤 트랙이든 좋아
보인다. 채점자와 피채점자를 분리하는 자리다.
