# 검수 안내 — Phase B-3

38개 프레임에서 **분석 대상이 누구인지** 사람이 직접 판단해 주세요.
이 판단이 Selector(A-pose / B-pose) 최종 결정의 근거가 됩니다.

소요: 프레임당 10~20초, 전체 10분 내외.

---

## 1. 무엇을 판단하는가

각 이미지에는 사람 검출 후보가 **전부 같은 하늘색 상자**로 그려져 있고,
왼쪽 위에 `번호  검출점수` 가 붙어 있습니다.

- 야구 33건 → **이 프레임에서 타자(batter)는 몇 번인가?**
- 축구 5건 → **이 프레임에서 공을 차는 선수(kick taker)는 몇 번인가?**

상자 색·굵기는 전부 같습니다. 어느 후보가 정답인지, 어떤 알고리즘이 무엇을 골랐는지
이미지에도 입력 파일에도 **들어 있지 않습니다.** 보이는 대로 판단하시면 됩니다.

## 2. 입력 방법

두 파일의 `human_box_index` 칸을 채우세요 (엑셀/텍스트 편집기 아무거나).

```
/mnt/d/supersub-phaseA/eval_b3/review_input.csv          야구 33건
/mnt/d/supersub-phaseA/eval_b3/soccer_review_input.csv   축구 5건
```

`image` 열이 볼 이미지 경로입니다 (`/mnt/d/supersub-phaseA/` 기준 상대경로).
윈도우 탐색기에서는 `D:\supersub-phaseA\eval_b2\review_cases\` 폴더입니다.

**입력할 수 있는 값은 세 가지뿐입니다.**

| 값 | 언제 |
|---|---|
| `0`, `1`, `2` … | 그 번호가 타자/키커라고 판단될 때 |
| `none` | 화면에 타자/키커가 없거나, 후보 상자 중에 없을 때 |
| `uncertain` | 봐도 모르겠을 때 |

**모르겠으면 억지로 번호를 고르지 마세요.** `uncertain`이 정상적인 답입니다.
그렇게 표시된 건은 평가에서 제외되며, 그게 잘못 넣는 것보다 낫습니다.

`human_note`는 선택 사항입니다 (예: "포수가 더 크게 잡힘", "펜스에 가려 판별 불가").

## 3. 판단이 애매할 때 참고

- 타자는 **배트를 들고 타석에 선 사람**입니다. 포수(보호장구·웅크림)와 심판(어두운 상의,
  포수 뒤에 서 있음)은 타자가 아닙니다.
- 이미 치고 **주루 중인 선수도 타자**로 봅니다 (그 클립의 분석 대상이므로).
- 상자 하나가 두 사람을 함께 감싸고 있으면 `uncertain`으로 두세요.
- 후보 상자가 실제 타자를 **하나도 포함하지 않으면** `none`입니다.
