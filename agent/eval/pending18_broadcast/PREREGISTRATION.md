2026.09.14 작성 · 🔴 **측정 스크립트를 쓰기 전에 커밋한다.** 상수·합격선·
판별 규칙·예측은 여기서 굳고 **결과를 보고 고치지 않는다.**

---

## 0. 11회차와 무엇이 같고 무엇이 다른가

**질문도 계기도 판별 규칙도 같다. 바뀌는 것은 표본 하나뿐이다.**

| | 11회차 | **12회차** |
|---|---|---|
| 표본 | 축구 19편 — **1인 훈련 영상** | **SoccerNet 방송 40편** (`Shots` 앞에서 40) |
| 다인률 | **8%** | **98%** |
| 주 층 | **1프레임 · 0클립** → 분모 0편 | **198프레임 · 9클립** |
| 사람 키 중앙 | 335px | 🔴 **28px** |
| 계기 | 박스 하단 중앙 ↔ 공 · 클립 중앙 키로 정규화 | **같다 — 코드를 import 한다** |
| 판별 규칙 | (가) `M ≥ 70%` · (나) `M ≤ 30%` 그리고 `margin ≥ 0.25` | **같다** |

🔴 **11회차 스크립트를 고치지 않고 `import` 한다.** 복제하면 두 회차의
계기가 조용히 갈라진다(미결 10번의 형태). `foot_point` · `gate_by_speed` ·
`detect_clip` · `analyse` · `layer` 를 그대로 부른다.

## 🔴 표본 관문을 **먼저** 통과시켰다 — 11회차가 못 한 것

11회차는 사전 등록·계기·판정을 다 갖추고 돌았는데 **표본에 현상이 없어서**
분모 0편으로 끝났다. 로드맵 5절이 그래서 계기 검사에 **셋째 줄**을 더했다 —
**「표본에 그 현상이 있기는 한가」**. 12회차는 **그것을 먼저 돌렸다**:

```
uv run python eval/sample_gate/sample_gate.py --sample soccernet
→ 다인률 98% ✅ · 발치+다인 2.5%(198f) · 그 층에 5프레임 이상인 클립 9/40 ✅
```

**이 값을 사전 등록에 적어 둔다.** 회차를 열 자격은 여기서 나온다.

---

## 1. 🔴 이 표본이 답하는 것과 **답하지 않는 것**

**답한다**: 한 화면에 여럿이 있을 때 `_largest_person_box` 가 **공을 다루는
사람을 고르는가.** 이것이 미결 18번(대상 선택)과 43번 ㉯(사람 목록)의 뿌리다.

🔴 **답하지 않는다** — 결과에도 이 문단을 그대로 옮긴다.

| | |
|---|---|
| **제품 성능이 아니다** | 방송 중계이고 제품 입력은 휴대폰이다. 「선택 규칙이 **어떻게** 깨지는가」를 재는 것이지 **「제품에서 몇 %가 깨지는가」가 아니다** |
| **채점을 못 묻는다** | 사람이 **28px** 다. ViTPose 에 먹이면 관절각이 소음이다. 이 회차는 **박스만** 쓴다 |
| **「공에 가까운 사람이 정답」이 아니다** | 공 근접은 **라벨이 아니라 물리적 개연성**이다. 최대치는 **「우리 규칙과 공이 서로 다른 사람을 가리킨다」**이고 **「공 쪽이 맞다」가 아니다** |

## 2. 상수 — 11회차에서 그대로 가져온다. **새로 고른 것은 둘뿐이다**

| 상수 | 값 | 출처 |
|---|---|---|
| `PERSON_ELIGIBLE_THRESHOLD` | **0.5** | production import. 🔴 **안 건드린다** |
| `NEAR` · `MIN_MARGIN` · `MIN_NEAR_FRAMES` | **0.25 · 0.25 · 5** | **11회차와 같다** |
| `MIN_BALL_COVERAGE` | **0.30** | 45번 1~3회차와 같다 |
| `MAX_BALL_SPEED_H` | **1.0** | 45번 3회차의 단위 변환 |
| 🔴 `JITTER_PX` | **1.0** px | **새로 고른다** — 아래 기준 B |
| 🔴 `JITTER_FLIP_MAX` | **20%** | **새로 고른다** — 아래 기준 B |

---

## 3. 🔴 기준 B 가 바뀐다 — **28px 에서 계기가 서는가**

11회차의 B 는 「박스 하단 중앙이 **발목**의 대리로 서는가」였고 ρ 0.835 로
통과했다. **그 검사를 여기서 다시 할 수 없다** — 28px 짜리 사람에게 ViTPose 를
돌려 얻은 발목은 그 자체가 소음이라 **대조군이 되지 못한다.**

**그래서 다른 것을 검사한다: 해상도다.**

거리를 **클립 중앙 키(`H` ≈ 28px)** 로 나누므로 **박스가 1px 흔들리면
0.036 키높이**가 움직인다. `NEAR` 가 0.25 인데 **잡음이 그 1/7** 이다.
그냥 넘어가면 11회차가 8회차에서 배운 것(「계기가 재려던 것을 재는가」)을
같은 자리에서 다시 밟는다.

> **기준 B (계기 검사)** — 주 층의 각 프레임에서 모든 후보 박스를
> **±`JITTER_PX`** 만큼 네 방향으로 흔들어 `argmin` 이 바뀌는 비율을 잰다.
> **`JITTER_FLIP_MAX`(20%) 이상 바뀌면 이 표본에서 계기가 안 서는 것**이고,
> 🔴 **그때는 `M` 을 판정에 쓰지 않는다.**

🔴 **판정을 못 하게 만드는 기준을 일부러 넣었다.** 11회차에서 배운 것이
그것이다 — 자기 회차를 무효로 만들 수 있는 검사가 없으면 계기는 늘 통과한다.

---

## 4. 주 지표와 판별 규칙 — **11회차와 같다**

`M` = 주 층(공이 발치 ≤`NEAR` **그리고** 후보 2명 이상) 프레임 중 **우리가
고른 사람이 공에 가장 가까운 후보**인 비율.

| 판정 | 조건 |
|---|---|
| **(가) 선택은 맞다** | `M ≥ 70%` |
| **(나) 선택이 틀린다** | `M ≤ 30%` **그리고** 불일치 `margin` 중앙 **≥ 0.25** |
| **판별불가** | 그 밖 · 또는 **기준 B 불통과** |

## 5. 합격 기준 A~G

| | 기준 | 왜 |
|---|---|---|
| **A** | 주 층에 **후보 1명 프레임 0건** | 단일후보는 구조적으로 100% 다(B-1 의 40.2% 오염) |
| **B** | 🔴 **계기 검사** — ±1px 섭동에서 `argmin` 이 바뀌는 비율 **< 20%** | 위 3절. **불통과면 `M` 을 판정에 안 쓴다** |
| **C** | `src/`·`rubrics/` **0줄 변경** | 조사 회차다 |
| **D** | **reach 보고** — 주 층이 전체 프레임의 몇 %인가 · 클립 몇 편인가 | 10회차의 2.6%. 작으면 결론의 범위를 그만큼 좁힌다 |
| **E** | **민감도** — `NEAR` 0.15/0.25/0.35/0.50 에서 판정 구간 불변 | 바뀌면 「문턱에 업혀 있다」고 **그렇게 적는다** |
| **F** | `uv run pytest -q` | 회귀 없음 |
| **G** | 🔴 **짝 기준 — 아래** | |

### 🔴 G — 예측을 미리 박는다. **그런데 나는 이미 한 프레임을 봤다**

관문을 돌린 뒤 **박스를 그려 눈으로 한 프레임을 봤고**, 거기서 공은 골문
앞인데 고른 사람은 화면 반대쪽 아래였다. **그러니 G 는 순수한 맹목 예측이
아니다 — 그 사실을 먼저 적는다.** 그래서 **바를 더 높여** 여전히 틀릴 수
있게 만든다.

> `M` 이 낮게 나온다면(`< 50%`) 그 기전은 **원근**이어야 한다 —
> 방송 구도에서 **「가장 큰 사람」 = 「카메라에 가장 가까운 사람」**이다.
> 그러면 **불일치 프레임에서 「고른 사람 박스 높이 ÷ 최근접 후보 박스 높이」의
> 중앙값이 `≥ 2.0`** 이어야 한다.

- 11회차 사후 관찰에서 이 값이 **6.77**(n=73, 다른 표본)이었다. **1.2 로
  두면 통과가 거의 보장**되므로 **2.0** 으로 올린다
- 🔴 **`M` 은 낮은데 높이비가 1.0 근처면** 기전이 설명되지 않는다 →
  **(나)로 적지 않고 판별불가로 내린다**
- `M ≥ 50%` 면 G 는 **해당 없음**이다

### 내 예측 (결과 전에 적는다)

**(나) 가 나올 것이라고 본다** — `M ≤ 30%`. 근거는 `_largest_person_box` 가
**면적**으로 고르는데 방송 구도에서 면적은 **카메라 거리**가 정하고, 공은
그것과 무관한 곳에 있기 때문이다. 🔴 **틀리면 틀렸다고 적는다** — 9회차에서
내 8회차 예측이 틀렸던 것을 그대로 남긴 것과 같이 한다.

## 6. 🔴 하지 말 것

- **`PERSON_ELIGIBLE_THRESHOLD`(0.5)를 낮추지 않는다** (43번)
- **`src/` 를 고치지 않는다.** 이 회차는 **진단**이다. (나)가 나와도 처방은
  13회차이고 거기서 사전 등록을 새로 세운다
- **11회차 스크립트를 고치지 않는다** — import 만 한다
- **결과를 보고 `NEAR`·`MIN_MARGIN`·70/30·`JITTER_FLIP_MAX`·G 의 2.0 을
  돌리지 않는다**
- 🔴 **방송 영상·프레임 그림을 저장소에 넣지 않는다.** 측정 결과만 커밋한다
- 🔴 **이 표본으로 관절각·등급·제품 성능을 말하지 않는다** (1절)
- **18번의 닫힌 경로 9개를 다시 열지 않는다** (로드맵 4절)
