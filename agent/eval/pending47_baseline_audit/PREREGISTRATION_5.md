## 🔴 하지 말 것

- **기준선 CSV 를 덮어쓰지 않는다.** C 가 0 이어도 (나)는 별도 결정이다
- **「평가가 옳았다/틀렸다」로 적지 않는다.** 이 회차가 답하는 것은 **무엇이
  값을 움직였나**뿐이다. **어느 전처리가 옳은가**는 다른 질문이고, 🔴 **배포
  환경(EC2)이 무엇을 쓰는지**를 봐야 답이 된다 — 그건 따로 올린다
- `eval_b2/eval_b2.py` 의 selector 가중치를 건드리지 않는다
- **C 가 0 이 아니라고 `torchvision` 가설을 급히 버리지 않는다** — 부분 원인일
  수 있고, 그때는 **남은 행이 무엇인지**가 다음 질문이다

## 예상 (틀리면 그대로 적는다)

**C 는 0 또는 0 에 매우 가까울 것**으로 본다.

🔴 **어떤 분포에서 나온 예상인지**: 근거는 ⑴ 시점이 딱 맞는다(마지막 재현과
깨짐 사이의 **유일한** 환경 사건) ⑵ 기전이 관찰된 모양(검출 그대로 · 포즈 이후만
움직임)과 맞는다 — **두 개뿐이고, 둘 다 「맞는 이야기」이지 측정이 아니다.**
13·14회차에서 기전 예측이 두 번 연속 틀렸으므로 **틀릴 자리를 미리 적어 둔다**:
전처리기가 갈려도 **리사이즈 결과가 실질적으로 같을** 수 있고(둘 다 bilinear),
그러면 C 는 85 그대로다.
