## 판정 규칙 (찾기 전에 고정)

| 결과 | 무엇을 적나 |
|---|---|
| **A 또는 B 로 md5 가 일치** | ⑴ **배제.** 그러면 남는 것은 ⑵ 뿐이고, ⑵ 는 기록이 없어 **영구 미결**이다 |
| **A 또는 B 로 md5 가 불일치** | ⑴ **확정.** 85행 차이의 원인이 **입력**이고, 그러면 기준선을 다시 세우는 (나)가 **정당해진다** |
| **A·B 둘 다 없음** | ⑴ 은 **영구 미결**로 선언한다. C 가 있으면 **방향만** 적고 🔴 **결론으로 쓰지 않는다** |

🔴 **승격 금지.** C(프레임 수·길이 같은 간접 성질)가 일치해도 **「같은 파일」이
아니다** — 재인코딩은 프레임 수를 보존한다. C 는 **「다르다」의 증거로는 강하고
「같다」의 증거로는 약하다.** 비대칭을 그대로 적는다.

🔴 **찾는 범위를 넓히다 이 회차를 끝내지 못하는 것을 막는다** — A·B 를 한 바퀴
돌고 끝낸다. 못 찾으면 **못 찾았다고 적는 것이 이 회차의 결과**다.

## 🔴 하지 말 것

- **(나)를 여기서 하지 않는다** — 기준선 재선언은 별도 회차다. 이 회차는
  **⑴ 을 가를 수 있는지**까지다.
- **`agent/data/` 의 파일을 고치거나 옮기거나 지우지 않는다.** 지금 것이
  **오늘의 기준선**이다(지문은 이미 떴다). 🔴 다른 사본을 찾더라도 **덮어쓰지
  않는다** — 덮으면 오늘 산출과 지문이 어긋나 상태가 하나 더 늘어난다.
- **`src/`·`rubrics/`·보존 자산 무변경.** GPU 안 쓴다.
- **못 찾은 것을 「아마 같을 것」으로 적지 않는다.**
