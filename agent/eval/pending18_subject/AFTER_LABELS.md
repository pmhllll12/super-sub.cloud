## 0. 🔴 먼저 정정 — 이것은 **10회차의 「사람 판독 70장」이 아니다**

14회차 결과에 *"(라) **사람 판독 70장**(10회차의 (A)) — 정답을 만드는 유일한
길이고, **(다)의 「공 쪽이 맞다」도 이것으로만 선다**"* 고 적었다. **틀렸다.**

| | 10회차의 (A) | **이 판독 ①** |
|---|---|---|
| 표본 | phaseA **야구** 클립의 **안 끝난 7구간** | **SoccerNet 축구 방송** 25클립 |
| 경로 | 사람이 **지정한** 대상의 추적(커버리지 붕괴) | **자동 선택**(`_largest_person_box`) |
| 묻는 것 | 「잃은 구간에 **대상이 보이는가**」 예/아니오 | 「이 프레임의 **분석 대상은 누구인가**」 후보 번호 |
| 분량 | 7구간 × 10프레임 = 70장 | **70프레임** |

**장수만 같고 다른 일이다.** 10회차의 (A)는 **그대로 열려 있고**, 11회차가
적어 둔 대로 그쪽도 **표본을 축구로 다시 뽑아야** 한다. 🔴 이 문서는 그것을
대신하지 않는다.

## 1. 무엇이 막혀 있어서 이 판독이 필요한가

11~14회차가 잰 `M` 은 **「우리가 고른 사람 = 공에 가장 가까운 후보」인 빈도**다.
`M(R0)` 가 층 A **17.7%** · 층 B **12.1%** 로 낮다. 🔴 **그런데 그 숫자는 둘
중 어느 쪽인지 말하지 못한다.**

| | |
|---|---|
| **(가)** | 우리 규칙이 틀린다 — 공 근접이 대상을 잘 가리킨다 |
| **(나)** | **공 근접이 대상을 안 가리킨다** — `M` 이 낮은 것이 우리 잘못이 아니다 |

**공 근접은 라벨이 아니라 물리적 개연성**이라고 11~14회차가 매번 적어 두었다.
**정답이 있어야 갈린다.** 그래서 이 판독이다.

그리고 같은 라벨이 **14회차의 결론을 독립적으로 확인**해 준다 — 거기서
「높이가 면적보다 나쁘다」를 **공 기준**으로 판정했는데, 여기서는 **정답
기준**으로 다시 잰다.

## 2. 분모 규칙 — 🔴 **먼저 걸러낸다**

| | |
|---|---|
| `unclear` · `none` | **분자·분모 양쪽에서 뺀다.** 「모르겠다」를 틀린 것으로도 맞은 것으로도 세지 않는다 |
| 🔴 **유효 분모가 한 자릿수면 정확도를 내지 않는다** | 분모만 보고한다. 미결 6번 사전 등록 6절과 같은 규칙이다(거기서 팔 종목 6/8 을 정확도로 안 냈다) |
| 층 A · 층 B | **따로 낸다.** 층 B 는 11~14회차에서 한 번도 규칙 선택에 안 쓴 층이다 |
| 🔴 `unclear` 비율이 **20% 를 넘으면** | 「판독이 성립하지 않았다」를 **먼저** 적는다. 그 위에서 낸 수치는 전부 조건부다 |

신뢰구간은 **Wilson 95%** 로 함께 낸다. 점추정만 적지 않는다.

---

## 3. 낼 수치 — 넷

`label` = 판독자가 고른 후보 번호. 아래는 전부 **유효 분모 위에서**.

| | 이름 | 정의 |
|---|---|---|
| **①** | `P_ball` | `label` == **공 최근접 후보** 인 비율 |
| **②** | `P_R0` | `label` == `argmax(area)` (**현행 규칙**) 인 비율 |
| **③** | `P_R1` | `label` == `argmax(height)` (14회차 R1) 인 비율 |
| **④** | 3-way | `label` 이 ①②③ 중 **아무것과도 안 맞는** 비율 |

🔴 **④ 를 반드시 함께 낸다.** ①②③ 이 전부 낮으면 **후보 목록 자체에 대상이
없다**는 뜻일 수 있고, 그건 선택 규칙 문제가 아니라 **검출 문제**다.

## 4. 판별 규칙 — **공 근접 축의 운명**

| 판정 | 조건 | 다음 |
|---|---|---|
| **공 근접이 선다** | `P_ball ≥ 70%` (층 A·층 B **둘 다**) | (다) **공 근접을 선택에 넣는 회차**를 연다 |
| 🔴 **공 근접을 닫는다** | `P_ball ≤ 30%` (둘 다) | 11~14회차의 `M` 은 **대상 정확도가 아니었다**. 로드맵 4절에 닫힌 경로로 올린다 |
| **판별불가** | 그 밖 · 또는 층이 엇갈림 | 그대로 적는다 |

🔴 **70/30 을 결과를 보고 옮기지 않는다.** 10회차에서 `LINK_IOU` 를 미리 못
박은 것이 「0.5 로 그었으면 78%가 결론이 됐을」 사고를 막았다.

### 🔴 짝 기준 — `P_ball` 만으로 결론 내지 않는다

> `P_ball` 이 높게 나오면(≥70%) **`P_R0` 는 낮아야 한다.** 그래야
> 「공은 맞히는데 우리 규칙이 틀린다」가 성립한다.
> **둘 다 높으면** 공 최근접과 `argmax(area)` 가 같은 사람을 가리킨다는
> 뜻인데, 그러면 `M` 이 12~18% 로 낮았던 것과 **모순**이다 —
> 🔴 그때는 **표본이 어긋난 것을 의심하고**(판독한 70장이 주 층을 대표하는가)
> 결론을 내지 않는다.

## 5. 🔴 이 판독으로 **말하지 않는 것**

- **제품 성능이 아니다.** SoccerNet 방송이고 제품 입력은 휴대폰이다
- **채점 정확도가 아니다.** 사람이 **28~86px** 다. 「누구인가」까지만 묻는다
- **10회차의 (A) 를 대신하지 않는다** (0절)
- 🔴 **AI 가 채우면 정답이 아니다.** 로드맵 2절 — B-3~B-5 의 선례가 그대로
  적용된다. **사람이 채운 것만 쓴다**
- 🔴 **판독자가 한 명이면 일치도를 못 낸다.** 두 명 이상이 같은 70장을 보면
  일치율을 함께 내고, 한 명이면 **그 한계를 결과에 적는다**

## 6. 표본을 어떻게 뽑았는가 — **라벨을 보기 전에 고정한다**

| | |
|---|---|
| 모집단 | 11~14회차의 **주 층** — 공이 어떤 후보의 발치(≤0.25 키높이)에 있고 **후보가 2명 이상**인 프레임. 층 A 198 + 층 B 264 = **462프레임** · **25클립** |
| 뽑는 법 | 🔴 **클립 라운드로빈.** 클립마다 시간상 가장 멀리 떨어진 프레임부터 1장씩 돌아가며 뽑아 **70장**을 채운다 |
| 왜 | 무작위로 70장을 뽑으면 **연속 프레임이 한 클립에 몰린다**(주 층이 클립당 5~53프레임이다). 그러면 70장이 70개의 독립된 관찰이 아니다 |
| 🔴 재현 | **난수를 안 쓴다.** 같은 입력이면 같은 70장이다 |

**번호 매기는 법**: 후보 박스를 **화면 왼쪽부터** 1, 2, 3 … 으로 붙인다.
🔴 **면적 순도 공 거리 순도 아니다** — 그러면 번호 자체가 힌트가 된다
(B-4 검수 패킷이 후보 상자를 전부 같은 색으로 그린 것과 같은 이유).
