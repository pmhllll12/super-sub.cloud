# 결과 — 골반 회전 지표가 축구에서도 카메라 축을 채점하는가 (미결 22번)

2026-09-09 · 재현:

```bash
cd agent && uv run python eval/jhmdb_batting/hip_axis_check.py \
    --root <joint_positions> --action kick_ball \
    --rubric football_instep_shot.yaml
```

정답 불필요 · GPU 불필요 · 약 1분. 입력은 JHMDB **사람이 붙인 관절**이라
포즈 추정 잡음이 섞이지 않는다 — 항목이 「n=4로는 지표 문제인지 포즈 품질
문제인지 못 가른다」고 적어 둔 그 구분을 위해서다.

## 🔴 먼저 — 항목의 「축구는 `--action` 만 바꾸면 된다」가 **틀렸다**

`hip_axis_span` 이 `identify_limb(norm, **"arm"**, ...)` 로 임팩트 사지를
박아 두고 있었다. 야구 타격은 `impact_limb: arm` 이라 맞지만 **축구 인스텝
슈팅은 `leg`** 다. 그대로 돌리면 **팔로 준비 구간을 잘라** 엉뚱한 창에서
골반을 잰다.

루브릭에서 읽도록 고쳤다(`--rubric`). 야구 기준선이 **그대로 재현되는 것**으로
수정이 동작을 안 바꿨음을 확인했다 — 중앙 16.7 · 0.298 · 상관 +0.568 · 11/46,
항목에 적힌 값과 같다.

| | 표본 수 |
|---|---|
| `leg` (루브릭대로) | **33클립** |
| `arm` (틀린 설정) | 27클립 |

## 측정

| | 야구 타격 (46) | **축구 kick_ball (33)** |
|---|---:|---:|
| 골반 축 각도 변화폭 중앙 | 16.7도 | **95.1도** |
| 축 단축률 중앙 | 0.298 | 0.716 |
| 각도 30도 미만 | 35/46 (**76%**) | **8/33 (24%)** |
| 🔴 둘 다 (안 돌았는데 짧아짐) | 11/46 (**24%**) | **6/33 (18%)** |
| 두 값의 상관 | +0.568 | **+0.713** |

## 답 — 축구에서는 **이 결함이 약하다**

각도가 30도 미만인 클립이 야구 76% 대 **축구 24%** 이고, 각도와 단축률의
상관이 +0.568 → **+0.713** 으로 올랐다. **인스텝 슈팅은 골반이 화면 평면
안에서 실제로 크게 돈다**(중앙 95도) — 항목이 「사정이 나을 수 있지만 확인된
바 없다」고 적어 둔 추측이 **확인됐고 맞았다.**

🔴 **사라진 것은 아니다.** 18%(6/33)는 여전히 「안 돌았는데 짧아졌다」이다.
야구의 24%보다 낮을 뿐이다.

## 🔴 그런데 반대쪽 문제가 드러났다 — **축구에서는 변별력이 없다**

임계값 검수 서식(`eval/pending2_bands/`)이 같은 항목에 대해 낸 실측이다.

| | 야구 타격 | **축구 인스텝** |
|---|---|---|
| 2등급 구간 | 30~120 | **25~180** |
| 실측 분포 | 중앙 16 (4~51) | 중앙 48 (11~161) |
| 그 선이 낸 등급 | 대부분 **0등급** | **잘함 14 · 보통 0 · 아쉬움 1** |

**같은 지표가 종목마다 정반대로 쏠린다.** 야구에서는 카메라 축 때문에 안 돌아
보여 대부분 감점되고, 축구에서는 실제로 크게 돌아 **15편 중 14편이 만점**이다.
2등급 구간이 25~180도로 넓어 사실상 모두를 통과시킨다.

**이쪽은 타당성이 아니라 임계값 문제다.** 즉 **검수 대상**이고, 서식이 이미
그 자리를 묻고 있다 — 「지금 선이 낸 결과: 잘함 14 · 보통 0 · 아쉬움 1」을
지도자에게 그대로 보여 준다.

## 무엇을 하지 않았나

- **밴드를 옮기지 않았다.** 항목의 「하지 말 것」 그대로다 — 분포에 맞춰
  낮추면 숫자는 퍼지지만 위 18% 에서는 여전히 카메라 축을 채점한다.
  🔴 그리고 축구 쪽은 **올려야** 하는데, 그것을 실측 분포만 보고 정하면
  이미 기각된 「분포에 맞춰 긋기」가 된다
- **실클립(RT-DETR→ViTPose)으로는 안 쟀다.** 위 33건은 사람이 붙인 관절이다.
  실클립 축구 15편의 중앙은 48도로 JHMDB 95도보다 **작다** — 포즈 추정이
  회전을 덜 잡는 방향이고, 야구에서 본 것과 같은 방향이다. 다만 둘 다
  임계값 25도를 크게 넘어 **등급 판정은 안 갈린다**
- **지표를 고치지 않았다.** 3차원 회전을 담으려면 깊이나 다중 시점이 필요하고,
  그것은 다른 제안이다
