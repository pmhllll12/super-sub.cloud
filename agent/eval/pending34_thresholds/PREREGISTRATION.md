# 사전 등록 — 임계값의 **출처**를 찾는다 (미결 `ho` 34번 결정 3)

작성 2026.09.12 · **찾기 전에 굳힌다.** 결과를 보고 아래를 고치지 않는다.

## 왜 이 회차인가

박민호 님이 2026.09.11 에 34번을 결정하며 셋째로 이것을 제 일감으로 잡으셨다:

> **임계값 출처 조사를 정상호 님 일감으로** — 스프린트 2~3 중 진행. 생체역학
> 문헌·공개 지도 자료를 인용해 등급 경계값을 「임의값」에서 「인용값」으로.
> 분포에 맞춰 긋지 않는다는 원칙은 그대로

33번 결정 2 가 제 스프린트 3 칸을 「채점 시스템 신뢰성 강화 — fps 불변성
원인 규명·개선 + 임계값 출처 조사」로 바꿨다. **이것이 그 둘 중 하나다.**

## 🔴 이 회차가 **하지 않는 것** — 먼저 적는다

| 안 한다 | 왜 |
|---|---|
| **임계값 숫자를 옮기기** | 밴드가 바뀌면 `features` 가 아니라 판정이 바뀌어 **그때까지의 등급이 전부 다른 값**이 된다. 옮길 근거가 생기더라도 그것은 **다음 회차의 사전 등록**이지 이 회차가 아니다 |
| **분포에 맞춰 긋기** | 34번에서 이미 기각됐다. 이 회차는 문헌을 보지 우리 표본을 보지 않는다 |
| **`threshold_validity` 등급을 올리기** | 문헌이 값을 든다는 것과 **우리 파이프라인이 그 값을 옳게 잰다**는 것은 다른 말이다. 측정 축이 반증된 지표가 이미 셋이다(`fps_dependence`·`trunk_forward_lean`·`hip_rotation_range`). 🔴 그 위에서 임계값만 「타당」이 될 수는 없다 |
| **초록만 보고 인용하기** | `tests/test_rubric_evidence.py::test_no_unverified_citation_reaches_the_document` 가 막는 것이 정확히 이것이다 |

## 무엇을 한다

축구 2종(`football/instep_shot` active · `football/inside_pass` draft)의 **세부기준
11개**에 대해, 밴드 경계값에 해당하는 **수치를 보고하는 원문**을 찾는다.
찾은 것은 `contracts/rubric_evidence.yaml` 의 해당 항목에
`citation` · `citation_verified: true` · `note`(문헌 값과 **우리 값의 차이**)로
적는다.

### 🔴 「확인했다」의 정의 — 이 회차의 핵심이다

아래 **넷을 다 만족**해야 `citation_verified: true` 를 쓴다. 하나라도 못 채우면
`cited_unverified` 에 머문다(또는 아예 안 적는다).

1. **원문 본문을 열었다.** 초록·인용 목록·2차 요약(리뷰의 표 포함)만으로는 안 된다.
   리뷰를 인용하려면 **그 리뷰 본문에 수치가 있어야** 하고, 그 경우 인용은
   리뷰이지 원 논문이 아니다 — 못 연 원 논문을 인용하지 않는다
2. **수치가 본문에 있다.** 「각도가 중요하다」는 문장은 임계값의 출처가 아니다
3. **우리가 재는 것과 같은 것을 잰다.** 관절·시점(임팩트/접촉)·단위·부호 규약이
   같은지 본다. 🔴 **다르면 다르다고 적고 인용하지 않는다** — 특히
   `trunk_forward_lean_deg_at_impact`(우리는 이미지 축이 섞여 있다, 37번)과
   `hip_rotation_range_deg`(회전의 24%만 담는다, 22번)
4. **접근 경로를 적는다.** URL 과 열람일. 링크는 `note` 가 아니라 `citation` 에
   (같은 검사가 `note` 안의 URL 도 막는다)

### 기록 형식

```yaml
    swing_knee_extension:
      biomechanical_basis:
        level: cited_verified        # ← 어휘에 새로 넣는다(아래)
        citation: "저자 (연도). 제목. 학술지 권(호), 쪽. URL (열람 2026-09-12)"
        citation_verified: true
        note: "문헌이 보고한 값 · 우리 밴드와의 차이 · 같은 것을 재는지"
      threshold_validity: {level: unverified}   # ← 🔴 안 올린다
```

`levels:` 에 **`cited_verified`** 를 새로 넣는다 — 「원문을 열어 확인했다.
문헌이 그렇게 보고한다. 🔴 **우리 임계값이 옳다는 뜻이 아니다.**」
`verified` 는 넣지 않는다(그 검사는 그대로 선다).

## 사전 등록된 판정 기준

이 회차는 **성능 측정이 아니라 조사**라 합격선을 「몇 건을 찾았는가」로 둔다.
🔴 **못 찾은 것을 못 찾았다고 적는 것도 결과다** — 그 자리가 지도자 검수
(미결 2번)에서 가장 먼저 물어볼 자리다.

| 기준 | 내용 | 판정 |
|---|---|---|
| **A** | 11개 세부기준 각각에 대해 **찾았다/못 찾았다**가 정본에 남는다 | 빠짐이 0이어야 합격 |
| **B** | `citation_verified: true` 가 붙은 항목이 **3개 이상** | 3 미만이면 **불합격**으로 적고, 왜 문헌이 안 서는지를 남긴다 |
| **C** | 🔴 `threshold_validity` 는 11/11 이 `unverified` 또는 `blocked` 로 **그대로** | 하나라도 올라가면 불합격 |
| **D** | 문헌 값이 우리 밴드와 **어긋나는 자리**를 전부 열거한다 | 어긋남을 숨기면 불합격 |
| **E** | `uv run pytest tests/test_rubric_evidence.py -q` 통과 | 실패면 불합격 |

**B 를 3으로 잡은 이유**: 두 차례 외부 검토가 인스텝 킥 쪽을 「근거가 가장
좋다」고 꼽았고 그 항목이 넷이다(디딤발 무릎·차는 다리 뻗기·상체·골반). 넷 중
셋도 원문 확인이 안 되면 **문헌 경로 자체가 우리 지표에 안 맞는다**는 뜻이므로
그것이 결과다. 🔴 **결과를 보고 3을 2로 낮추지 않는다.**

## 🔴 미리 적어 두는 함정

- **리뷰가 원 논문을 요약한 수치를 원 논문 이름으로 인용하는 것.** 리뷰 본문의
  표를 봤으면 인용은 리뷰다. 이 저장소는 「없는 근거를 있다고 말하는 것」을
  가장 나쁜 형태로 친다
- **단위·부호.** 무릎각이 「굴곡각」인지 「내각」인지에 따라 `140도` 가 정반대다.
  우리는 **내각**(펴면 180도)이다. 🔴 문헌이 굴곡각이면 `180 − x` 로 옮겨
  적고, 옮겼다는 사실을 `note` 에 적는다
- **종목·기술.** 인스텝 킥의 값을 인사이드 패스에 옮기지 않는다 — 정본이
  이미 그렇게 경고해 두었다(`inside_pass.plant_foot_position`)
- **접근 못 하는 원문.** 페이월이면 **`cited_unverified` 에 머문다.** 초록에
  수치가 있어도 본문을 못 봤으면 3번 조건(같은 것을 재는가)을 못 채운다
- **🔴 일치를 성과로 읽기.** 문헌 값이 우리 밴드와 겹쳐도 그것은
  **「우리 값이 문헌 범위 안에 있다」**까지다. 우리 포즈 추정이 그 각도를
  옳게 재는지는 별개이고, 그쪽은 지금 반증된 것이 셋이다
