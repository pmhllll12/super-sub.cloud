# 임계값 검수 서식 (미결 2번 (A))

**지도자에게 내밀 종이입니다.** 섭외가 되면 이 폴더의 `packet/*.md` 를 인쇄하거나
그대로 보내면 됩니다.

```bash
cd agent && uv run python eval/pending2_bands/build_review_packet.py --write
```

## (A)는 클립을 보는 일이 아닙니다

미결 2번이 (A) 임계값 검수와 (B) 정답 라벨을 갈라 둔 이유가 여기 있습니다.

| | (A) 임계값 검수 ← **이 폴더** | (B) 정답 라벨 |
|---|---|---|
| 지도자가 보는 것 | **숫자와 구간** | 클립 |
| 필요한 것 | 지도자 1명 · 한 시간 | 표본 수(수십~수백 클립) |
| 적은 수로 시작 | ✅ 된다 | 🔴 안 된다 |

**클립을 한 편도 안 보고 답할 수 있게** 만들었습니다. 「이 종목에서 무릎이 몇
도쯤이면 잘 찬 것입니까」를 묻는 자리입니다.

## 지금 낼 수 있는 것

| 루브릭 | 상태 | 참고 분포 |
|---|---|---|
| 축구 · 인스텝 슈팅 | **active** | **18편** ← 여기부터 |
| 야구 · 타격 | draft | 46편 (JHMDB) |
| 농구 · 점프슛 | **active** | 1편 |
| 농구 · 레이업 | draft | 1편 |
| 야구 · 투구 | **active** | **0편** |
| 축구 · 인사이드 패스 | draft | **0편** |

🔴 **야구 투구는 참고 분포가 없습니다.** 가진 클립 한 편이 품질 게이트에
걸립니다(상반신 키포인트 유효 프레임 51% < 기준 70%). **그래도 서식은
쓸 수 있습니다** — 분포는 참고 자료이지 질문의 조건이 아닙니다. 다만
「우리 선수들이 어디쯤에 몰려 있는가」를 못 보여 드립니다.

**축구부터 하는 것이 맞습니다.** 표본이 18편으로 유일하게 분포다운 분포입니다.

## 서식이 일부러 안 하는 것

- 🔴 **처방을 미리 적지 않습니다.** 지금 구간이 이상해 보이는 자리를 알고
  있지만(미결 20·22번) 서식에 안 적습니다 — 유도하면 검수가 아니라 확인이
  됩니다. 결과를 받은 뒤에 대조합니다
- 🔴 **분포에 맞춰 선을 그으라고 하지 않습니다.** 우리 표본이 잘하는 선수들이
  아닐 수 있습니다. 그 문장을 서식 첫머리에 적어 두었습니다
- **「모르겠다」와 「이 항목은 빼야 한다」를 답으로 받습니다.** 그것도 결과입니다
