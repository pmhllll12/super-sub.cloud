## 1. 슛하는 팔 뻗기

> 릴리스 순간 팔이 완전히 뻗어야 공을 가장 높은 지점에서 놓을 수 있다. 팔이 굽은 채 놓으면 릴리스 지점이 낮아져 블록에 걸리고 백보드 각도도 얕아진다.

**재는 것**: 임팩트 시 주동 팔 팔꿈치 각 (단위: 도)

| | 지금 선 |
|---|---|
| 잘함 | 160~180 |
| 보통 | 140~160 |
| 아쉬움 | 140 이하 |
