# 사전 등록 — 거부·재획득 (미결 18번 처방 2회차)

**작성 2026.09.09 · 정상호 · 프로토타입 코드보다 먼저 고정한다.**

1회차(`eval/pending18_appearance/`)에서 **재가중은 원리적으로 안 된다**는
것이 나왔다 — 갈아타는 프레임에 **겹치는 후보가 1개뿐**이라 무엇을 곱해도
argmax 가 안 바뀐다. 그런데 **외양 신호 자체는 갈렸다**(깨끗 중앙 0.81~0.98
대 갈아탐 0.26~0.72). 쓸 자리가 없었을 뿐이다.

**그래서 이번에는 「고르는 방법」이 아니라 「안 고를 수 있는가」를 시험한다.**

## 무엇을 바꾸는가 — 한 가지만

지금 구조에는 **「아무것도 고르지 않는다」는 선택지가 없다.** 겹치는 후보가
하나라도 있으면 반드시 고른다. 여기에 둘을 더한다.

| | |
|---|---|
| **거부** | 이어갈 후보의 외양이 닻과 **오래** 어긋나면 고르지 않는다 → 그 프레임은 `None` |
| **재획득** | 잃은 뒤에는 IoU 사슬을 버리고, **외양으로** 닻과 맞는 후보를 찾아 다시 붙는다 |

🔴 **`None` 은 새 규약이 아니다.** production 이 이미 사람이 검출되지 않은
프레임을 `None` → 키포인트 신뢰도 0으로 처리한다(`extract_keypoints`).
**「못 쟀으면 값을 내지 않는다」** 는 미결 21번이 세운 원칙 그대로다 —
엉뚱한 사람의 자세를 지정 대상의 것으로 내보내지 않는다.

⚠️ **겹치는 후보가 0개인 기존 끊김은 건드리지 않는다.** 거기서 production 은
자동 박스로 떨어지는데, 그 판단이 옳은지는 **이 회차의 질문이 아니다.**
바꾸는 것은 「외양 때문에 거부한 경우」 하나뿐이다.

## 🔴 자유도가 넷이고 시험 표본이 **2건**이다 — 그래서 나눈다

거부·재획득에는 문턱과 지속 길이가 필요하다. 갈아탄 클립은 3건이고 그중
하나(`Fz16t9SrF3U`)는 가림 계열이라 **실질 2건**이다. **2건에 네 값을 맞추면
그것은 측정이 아니라 외우기다.**

그래서 **표본을 나눈다. 이 분할은 여기서 고정하고 결과를 보고 바꾸지 않는다.**

| | 클립 | 쓰임 |
|---|---|---|
| **보정용** | 깨끗한 **7건** | **문턱을 여기서만 정한다.** 갈아탐 여부를 안 쓴다 |
| **시험용** | 갈아탄 **3건** | 정해진 문턱으로 **한 번** 잰다 |

🔴 **시험용 클립을 보고 문턱을 고치면 이 회차는 무효다.** 고치고 싶으면
3회차로 새로 사전 등록한다.

## 상수 — 값이 아니라 **정하는 규칙**을 박는다

| | 규칙 | 왜 |
|---|---|---|
| `TAU` (외양 문턱) | **0.6 고정** | 1회차 보고에서 이미 쓴 값이다. 분포를 보고 고른 것이 아니라 보고용 반올림 값이었고, 그대로 쓴다 |
| `K` (거부까지 필요한 연속 프레임) | **보정용 7건에서 「app < TAU 가 연속으로 이어진 최대 길이」 + 1** | 🔴 **깨끗한 클립이 하나도 안 끊기는 가장 짧은 길이**다. 시험용을 안 본다. 1회차가 「프레임 하나로는 못 가른다」를 이미 보였으므로(깨끗 최소 0.49 = 갈아탐 최소 0.49) 지속 길이로 가른다 |
| `REACQ_TAU` (재획득 문턱) | **0.6 (= `TAU`)** | 두 값을 따로 두면 자유도가 하나 더 는다. 같게 둔다 |
| `REACQ_K` (재획득에 필요한 연속 프레임) | **2 고정** | 한 프레임만 맞아도 붙으면 깜빡임에 붙는다. 가장 작은 「연속」이 2다 |

**`K` 만 데이터에서 오고, 그 데이터는 보정용뿐이다.**

## 합격 기준 — 넷 다 만족해야 구현을 권고한다

| | 기준 | 왜 이것인가 |
|---|---|---|
| **A** | **자동 경로 비트 동일** | 🔴 깨지면 B-2\~B-6 전체가 무효다. 지켜지면 **B-6 재실행을 안 부른다** |
| **B** | **보정용 7건이 기준선과 동일**하다 (선택 박스 전부) | `K` 를 그렇게 정했으므로 **당연히 만족해야 한다.** 안 되면 규칙을 잘못 구현한 것이다 — 이 기준은 그 버그를 잡는 자리다 |
| **C** | 시험용 3건 중 **2건 이상**에서 「엉뚱한 사람 프레임」이 **70% 이상 준다** | 「엉뚱한 사람 프레임」 = 박스가 있고 그 박스의 app < `TAU` 인 프레임. `3R1kvNrGJK0` 기준선이 **190/300** 이다 |
| **D** | 시험용 3건의 **대상 커버리지가 기준선의 50% 이상** 남는다 | 🔴 **이 기준이 없으면 「전부 거부」가 만점을 받는다.** 아무도 안 따라가면 C 는 자동으로 만족된다. 고치는 것과 포기하는 것을 가른다 |

**보조(합격 조건 아님)**: 고쳐졌다는 클립의 프레임을 그려 본다.
🔴 **AI 판독이라 반증에만 쓴다** — 수치는 합격인데 눈으로 보니 엉뚱하면
불합격으로 뒤집고, 반대 방향으로는 뒤집지 않는다.
