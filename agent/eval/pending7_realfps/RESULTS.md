## 편향이 아니라 산포다

부호를 보면 **올라간 것 4 · 내려간 것 2 · 그대로 1** 이다(부호 있는 평균
+9.7점). **한쪽으로 쏠리지 않는다** — 미결 7번이 기록해 둔 「편향이 아니라
산포다」와 같은 결론이다.

🔴 **처음 판본은 이것을 말할 수 없었다.** `abs()` 를 취한 뒤 `+` 형식으로 찍어
전부 양수처럼 보였다. 그대로 읽었으면 **「fps 를 낮추면 점수가 오른다」는
없는 편향을 보고할 뻔했다.** 부호를 살려 다시 돌렸다.

## 한계 — 이 값을 어디까지 쓸 수 있나

- **표본이 작다.** 4클립·성공 7변형이다. **비율(29% · 86%)을 정밀한 값으로
  읽지 말 것** — 크기의 자릿수를 보는 용도다
- **하향 폭이 크다.** 1/3 은 8~10fps 로 실제 업로드에서 드물다. **1/2 만 봐도**
  4편 중 1편 반려 + 3편이 13~38점 움직인다 — 12~15fps 는 현실적 하한에 가깝다
- **원본 fps 가 24~30 으로 낮다.** 기존 모의는 60fps 기준이라 조작 폭이 더
  컸다. 두 값을 직접 비교할 수 없다
- 🔴 **`pending7_fps` 의 「60↔30 등급 37%」를 대체하지 않는다.** 그쪽은 외부
  포즈를 솎은 모의이고 이쪽은 파일을 다시 만든 실측이다. **둘 다 남긴다**
