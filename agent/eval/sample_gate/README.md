# 표본 관문 — 회차를 열기 **전에** 돌린다 (2026.09.14 신설)

```bash
cd agent && uv run python eval/sample_gate/sample_gate.py --sample soccer
cd agent && uv run python eval/sample_gate/sample_gate.py --sample phasea
cd agent && uv run python eval/sample_gate/sample_gate.py --sample soccernet   # 미결 46번
```

🔴 **판정 회차가 아니다.** 가설을 재지 않고 사전 등록도 없다. 여기 숫자는
**회차를 열지 말지**를 정하는 데 쓰고, 열기로 하면 그 회차의 사전 등록에
이 값을 적는다.

## 왜 있는가

미결 `ho` 18번 **11회차**가 사전 등록·계기·판정을 다 갖추고 돌았는데
**주 층이 19편에서 1프레임**이라 분모가 0편으로 끝났다. 표본에 **후보가
2명 이상인 프레임이 8%** 뿐이었고, **그 값은 검출 한 번이면 나왔다.**

로드맵 5절의 계기 검사가 그래서 **셋**이 됐다.

| | 묻는 것 | 틀렸던 회차 |
|---|---|---|
| ① | 이 **양**이 내가 묻는 것인가 | 8회차 (`cont_iou` 가 구간 길이를 쟀다) |
| ② | 이 **표본**이 내가 묻는 대상인가 | 10회차 (재획득 구간만 봐서 현상의 2.6%) |
| ③ | **표본에 그 현상이 있기는 한가** | **11회차** (계기는 맞았는데 현상이 없었다) |

이 스크립트가 ③이다.

## 무엇을 내는가

검출 한 번(**ViTPose 를 안 돌린다**)으로 셋을 센다. production 함수를
**import 만** 한다 — `_eligible_person_boxes` · `_tracked_centers` ·
`stack_object_tracks` · `read_frames_ex`.

| | |
|---|---|
| ⑴ **다인률** | 후보(`score ≥ PERSON_ELIGIBLE_THRESHOLD`)가 **2명 이상**인 프레임 비율 |
| ⑵ **공 검출률** | 45번 3회차의 속도 게이트를 통과한 공이 있는 프레임 비율 |
| ⑶ **발치+다인** | 공이 어떤 후보의 발치(≤0.25 키높이)에 있고 **동시에** 후보가 2명 이상 — 18번 11회차의 **주 층** |

🔴 **바(bar)는 결과를 보기 전에 정했다** (2026.09.14): 다인률 **10%** 미만이면
「여러 명 중 고르기」 회차를 **그 표본으로 열지 않는다.** 결과를 보고 내리면
관문이 아무것도 안 막는다.

### 🔴 대조군이 세 가지를 한꺼번에 확인해 준다

**⑴ 관문이 고장 난 것이 아니다.** 야구 **66%** 대 축구 **8%** 로 여덟 배
갈린다. 대조 없이 「8% 라 표본이 나쁘다」고 적으면 10회차와 같은 형태의
결함이다 — **낮은 값이 표본 탓인지 계기 탓인지 그 자체로는 말 못 한다.**

**⑵ `soccer` 8% 는 11회차 값을 그대로 재현한다** (101/1297 · 주 층 1프레임).
도구가 그 회차에서 나왔으니 **재현이 안 되면 도구가 틀린 것**이다.

**⑶ 공 검출의 종목 비대칭도 재현된다.** 야구 **23%** 대 축구 **69%** —
45번 1회차가 `gate_raw.json` 에서 「야구 39편 중 공 궤적이 남은 것 12편(31%)」
이라고 적은 것과 같은 방향이다.

### 🔴 `soccernet` 은 통과했지만 **읽는 법을 좁혀 적는다** (2026.09.14)

**⑴ 관중은 안 잡힌다.** 프레임에 박스를 그려 눈으로 봤다 — 검출된 것은
**전부 필드 위 선수**이고 관중석은 **하나도** 0.5 를 못 넘는다. 「다인 98%」가
관중을 센 것이 아니냐는 의심은 **배제됐다.** (그림은 `/tmp` 에서만 봤다 —
🔴 **방송 프레임은 저장소에 안 넣는다**, 3DSP 와 같은 취급.)

**⑵ 🔴 사람이 28px 다.** `soccer`(335px)·`phasea`(187px)와 자릿수가 다르다.
**이 표본으로 물을 수 있는 것은 「어느 박스를 고르는가」까지**이고,
**키포인트가 필요한 것(관절각·등급)은 못 묻는다** — ViTPose 를 28px 에
먹이면 나오는 값이 소음이다. 18번 11회차의 계기는 **박스만** 쓰므로
그 질문에는 쓸 수 있다.

**⑶ 공 검출률이 15%** 로 낮다(224p 에서 공이 몇 픽셀이다). 그래도 주 층이
**198프레임 · 9클립**이라 11회차(1프레임 · 0클립)와는 자릿수가 다르다.

**⑷ 🔴 방송 중계이지 제품 입력(휴대폰)이 아니다.** 선택 규칙이 **깨지는 것을
보이는** 데는 쓸 수 있어도 **제품 성능을 말하지 않는다.**

### ✅ 그리고 논증이던 것이 **측정**이 됐다

45번 1회차는 *"야구는 공이 발치에 없다 — 저 물리는 축구의 것이다"* 라고
**원리로** 적고 재지는 않았다. 이번에 **발치+다인 층이 야구에서 0.4%(44프레임,
39편 중 1편)** 로 나왔다. 🔴 **공을 23%나 보면서도 그렇다** — 공이 안 잡혀서가
아니라 **발치에 없어서**다. 이제 「야구로 대신하자」는 곁길이 **숫자로** 닫힌다.
