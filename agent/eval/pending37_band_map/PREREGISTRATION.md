# 사전 등록 — 밴드 반전 **지도**: 표본 없이 구조를 전수로 (미결 `ho` 37번 2회차)

**작성 2026.09.10 · 정상호 · 측정 코드보다 먼저 고정한다.**

## 🔴 먼저 — 1회차가 적은 「표본 메우기」는 **지금 못 한다**

1회차 결과가 「다음은 표본 메우기」라고 적었다. 재고를 세어 보고 **정정한다.**

| 필요한 것 | 있는 것 |
|---|---|
| 야구 투구 클립 | `data/baseball_pitch_trim.mp4` **하나뿐**이고 그것이 `InsufficientQuality`(상반신 키포인트)로 이미 탈락한 클립이다 |
| 축구 인사이드 패스 클립 | **0개.** 축구 골든셋 19편은 전부 `*_penalty*` · `*_freekick*` — **인스텝**이다 |
| 그 밖 | `vru_sample` 2편은 보행자 데이터라 종목이 아니다 |

**촬영·수집 없이는 못 채운다.** 그래서 같은 질문을 **둘로 가른다.**

> **구조(밴드가 어떻게 생겼나)는 표본 없이 전수로 답할 수 있다.
> 분포(실측 θ 가 어디 떨어지나)는 그 두 루브릭에서 못 답한다.**

이 회차는 **구조만** 한다. 🔴 **분포를 답한 척하지 않는다.**

## 무엇을 내나

`trunk_forward_lean_deg_at_impact` 의 **정의역 전체**에 대해, 각 루브릭이
매기는 등급 `g(θ)` 와 반전 등급 `g(-θ)` 를 비교한 지도다.

- 뒤집히는 θ 구간이 **정확히 어디인가**
- 몇 등급이 뒤집히는가 (Δ = 1 인가 2 인가)
- 정의역의 **몇 %** 가 뒤집히는가
- 그것이 **총점 몇 점**인가

**표본 추정이 아니라 전수다.** 1회차가 18클립으로 「44%」를 낸 자리를,
이번엔 「정의역의 몇 %가 구조적으로 뒤집히는가」로 바꿔 답한다.

## 🔴 고정할 자유도는 둘뿐이고, 둘 다 내 선택이 아니다

이 회차는 결정론적 전수 계산이라 **결과를 보고 바꿀 수 있는 것이 거의 없다.**
그래도 아래 둘은 고르기에 따라 「% 」가 달라지므로 미리 박는다.

| | 값 | 어디서 왔나 |
|---|---|---|
| **정의역** | `(-90, 90)` | 🔴 **`features.py` 의 `PLAUSIBLE` 선언 그대로다** — 내가 고른 범위가 아니다. *"상체가 앞뒤로 90도를 넘으면 뒤집힌 자세다 — 측정이 깨진 것으로 본다"* |
| **격자** | **0.1도** | 밴드 경계가 전부 정수라 0.1도면 경계를 놓치지 않는다 |

🔴 **정의역을 「실제로 나오는 범위」로 좁히지 않는다.** 그렇게 하면 표본에
맞추는 일이 되고, 애초에 **표본이 없는 두 루브릭을 답하려고** 하는 회차다.

## 합격 기준

이 회차도 처방이 아니라 **측정**이라 「합격」이 성과를 뜻하지 않는다.

| | 기준 |
|---|---|
| **A** 🔴 | **자기 검사** — 야구 타격(대칭 밴드)은 뒤집히는 구간이 **정확히 0%** 여야 한다. 나오면 지도 구현이 틀린 것이다 |
| **B** | `g(θ)` 가 production 경로(`Criterion.grade_for`)로 나와야 한다 — 밴드를 다시 구현하지 않는다 |
| **C** | 1회차 실측과 **어긋나지 않아야** 한다 — 인스텝 18클립의 θ 를 지도에 얹으면 1회차가 센 18/18 이 재현돼야 한다 |
| **D** | 🔴 `features.py`·`rubrics/`·앞 회차 스크립트 미수정 (import 만) |

## 반드시 보고할 것

1. 루브릭별 **뒤집히는 정의역 비율**과 **Δ=2(2등급 차) 구간**
2. 🔴 **투구·인사이드 패스** — 표본이 없어 1회차가 못 잰 둘의 **구조**
3. 그것이 **총점 몇 점**인가 — `score = Σ(wᵢ/Σw)·(gᵢ/2)·100` 이므로 한 항목이
   Δg 뒤집히면 `(w/Σw)·(Δg/2)·100` 점이다. 🔴 **`Σw` 는 적용된 항목의 합**이라
   도구 미검출로 항목이 빠지면 **영향이 커진다** — 하한과 상한을 함께 적는다
4. **0 을 경계로 쓰는 루브릭**이 몇 개인가 — 그 경계는 측정 잡음에 가장 약하다

## 미리 적는 예측

| | 예측 |
|---|---|
| A | 만족한다 — 밴드가 0 대칭이다 |
| 투구 | **가장 나쁠 것이다.** 2등급 `[15,40]` · 0등급 `≤0` 이라 **양수 전체가 0등급으로** 갈 것이다 |
| 인사이드 | 투구와 같은 구조(0등급 `≤2`)라 비슷할 것이다 |
| 점프슛·레이업 | 밴드가 0 을 걸치고 있어 **덜할 것이다** — 다만 0% 는 아닐 것이다 |
| 🔴 **모르는 것** | **정의역 비율이 얼마나 큰지**를 나는 모른다. 「대부분 뒤집힌다」와 「좁은 구간만」은 처방 선택을 다르게 만든다 |

**빗나가면 빗나간 대로 적는다.**

## 하지 않는 것

- 🔴 **처방을 고르지 않는다.** (가) 밴드 대칭화 · (나) 방향 인식 지표 중
  어느 것도 이 회차에서 정하지 않는다 — 지도는 **고르는 데 필요한 숫자**다
- 🔴 **밴드를 고치지 않는다** (임계값 이동 — 미결 2번·34번)
- 🔴 **`features.py` 를 고치지 않는다** (B-6 전 구간 재실행)
- 🔴 **분포를 답한 척하지 않는다** — 투구·인사이드 패스는 **구조만** 나온다
- **정의역을 표본에 맞춰 좁히지 않는다**

## 한계

- ⚠️ **정의역 비율은 「얼마나 자주 나는가」가 아니다.** 실측 θ 가 균등분포일
  이유가 없다. 🔴 **인스텝·타격은 실측이 있어 둘을 같이 볼 수 있지만,
  투구·인사이드 패스는 구조만 안다**
- ⚠️ 여전히 **정답이 없다** — 「어느 부호가 옳은가」는 못 말한다
- ⚠️ 지도는 `trunk` 항목 **하나**의 등급만 본다. 총점은 다른 항목과 섞이고,
  적용 항목 수가 클립마다 달라 점수 영향이 범위로만 나온다
