2026.09.15 · 🔴 **구현 전에 굳힌다.** 결과를 보고 이 문서를 고치지 않는다.

## 무엇을 고치는가

`extract_features` 의 감속 탐색이 **구간이 아니라 클립 끝까지** 본다.

```python
ankle_speed = np.linalg.norm(np.diff(xy[:, swing_ankle], axis=0), axis=1)
post = ankle_speed[t:]          # 🔴 창도 유효 구간도 아니다
```

2회차(`eval/pending43_dribble_metrics/`)가 이것을 쟀다 — `L`=10 에서 짝의
**35%**가 창 끝을 넘겨 감속을 찾았고, 창을 걸어도 값이 **한 건도** 안 바뀌었다.
반복 동작이면 **다음 터치의 발 속도**를 이번 마무리로 센다.

**고치는 것은 한 줄**이다: `post = ankle_speed[t:ft_end]`.
(`ft_end` = `phases.follow_through[1]`. `segment_phases` 가 `last - impact >= 2`
를 보장하므로 **빈 `post` 는 새로 생기지 않는다.**)

🔴 **이번 회차는 구현 회차다** — 2회차와 달리 `src/` 를 **의도적으로** 고친다.
그래서 **변경 전 스냅샷을 먼저 뜨고**, 고친 뒤 대 본다(45번 4회차와 같은 형태).
