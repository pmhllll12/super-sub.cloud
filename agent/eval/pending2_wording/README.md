# 문구 검수 서식 (미결 2번 — 문구 축)

**지도자에게 내밀 종이입니다.** 섭외가 되면 이 폴더의 `packet/*.md` 를 인쇄하거나
그대로 보내면 됩니다.

```bash
cd agent && uv run python eval/pending2_wording/build_review_packet.py --write
```

## 옆 폴더(`pending2_bands`)와 **묻는 것이 다릅니다**

| | `pending2_bands` | **이 폴더** |
|---|---|---|
| 묻는 것 | **숫자** — 구간을 어디서 가릅니까 | **말** — 이 문장이 그 동작을 맞게 부릅니까 |
| 지도자가 보는 것 | 실측 분포와 구간 | 문장과 (참고용) 기준 |
| 걸리는 시간 | 한 시간쯤 | 훨씬 짧습니다 — 표만 읽습니다 |
| 막고 있는 것 | 임계값 확정(20·22·23(나)·6·draft 승격) | 선수에게 **검수 안 된 문장이 나가는 것** |

🔴 **한 장에 합치지 않았습니다.** 섞으면 지도자가 한 번에 둘을 판단하게 되고,
돌아온 답이 어느 쪽에 대한 것인지 모르게 됩니다. **같은 자리에서 두 장을 내미는
것은 됩니다** — 문구 쪽이 먼저 끝납니다.

## 무엇을 검수받습니까

선수가 **화면에서 그대로 읽는 문장** 둘입니다. 둘 다 루브릭에 **데이터로**
살고, 그렇게 둔 이유가 사람이 검수할 수 있게 하려는 것이었습니다.

| | 어디에 보이나 | 루브릭 |
|---|---|---|
| 칭호 | 분석 결과의 항목 이름 옆 · 추천 카드의 수식어(**잘함 등급만**) | `titles` |
| 카드 문장 | 추천 목록에서 이름 아래 한 줄 | `card_lines` |

## 지금 낼 수 있는 것

| 루브릭 | 상태 | 항목 |
|---|---|---|
| 축구 · 인스텝 슈팅 | **열려 있음** | 6개 |
| 축구 · 인사이드 패스 | 아직 안 연 동작 | 5개 |

**클립 표본이 필요 없습니다.** 옆 폴더는 분포를 보여드려야 해서 표본 0편인
루브릭이 약했지만, 여기는 문장만 읽으면 되므로 **지금 두 장 다 낼 수 있습니다.**
아직 안 연 동작까지 내는 이유는, 여는 시점에 또 검수를 받지 않으려는 것입니다.

## 서식이 일부러 안 하는 것

- 🔴 **처방을 미리 적지 않습니다** (옆 폴더와 같은 규칙). 어색해 보이는 문장을
  알고 있어도 표시하지 않습니다 — 유도하면 검수가 아니라 확인이 됩니다
- 🔴 **숫자를 같이 묻지 않습니다.** 「기준」 칸은 문장이 어느 동작을 가리키는지
  보여드리는 참고일 뿐이라고 종이에 적어 두었습니다
- **「이 문장은 아예 빼는 게 낫다」를 답으로 받습니다.** 그것도 결과입니다

## 받은 뒤에 할 일

1. 답을 이 폴더에 **원본 그대로** 둡니다(고쳐 쓰지 않습니다)
2. 반영은 **루브릭(`rubrics/*.yaml`)** 에 하고 서식을 다시 뽑습니다. 🔴 종이를
   손으로 고치면 판이 둘 생깁니다 — `tests/test_coach_review_sheet.py` 가
   루브릭과 어긋난 서식을 막습니다
3. 🔴 **점수는 안 건드립니다.** 문장은 판정에 관여하지 않으므로 이 반영은
   **B-6 재실행을 부르지 않습니다** — 임계값 검수와 가장 크게 다른 점이고,
   그래서 먼저 받아도 안전합니다
