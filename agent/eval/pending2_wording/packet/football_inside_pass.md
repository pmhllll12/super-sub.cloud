## 무엇을 봐 주시면 되나요

선수가 **화면에서 그대로 읽는 문장** 둘입니다.

| | 어디에 보이나 |
|---|---|
| **칭호** | 분석 결과에서 항목 이름 옆. 추천 목록에서는 **「잘함」 등급만** 이름 아래 수식어로 씁니다 |
| **카드 문장** | 추천 목록에서 선수 이름 아래 한 줄 |

**세 가지만 봐 주시면 됩니다.**

1. **그 구간의 동작을 맞게 부르고 있습니까.** 「보통」 자리의 문장이 실제로는
   「아쉬움」에 가까운 말을 하고 있지는 않은지.
2. **선수가 읽어도 되는 말입니까.** 아쉬운 등급이라도 **무엇을 고치면 되는지**가
   보이면 좋고, 사람을 깎는 말이면 안 됩니다.
3. **「잘함」 문장이 칭찬으로 읽힙니까.** 한 번 틀린 자리입니다 — 잘한 항목에
   지적처럼 들리는 칭호가 붙어 있었습니다.

## 숫자는 이 종이에서 안 여쭙니다

표의 「기준」 칸은 그 문장이 **어느 동작을 가리키는지** 알려드리려고 같이 놓은
것입니다. 🔴 **그 숫자가 맞는지는 다른 종이에서 따로 여쭙습니다.** 지금은 전부
검수 전 임시값입니다 — 숫자가 이상해 보이시면 문장 대신 그 점만 한 줄 적어
주십시오.

## 답은 어떻게 적나요

**고치실 문장만** 맨 오른쪽 칸에 적어 주십시오. 비워 두시면 「그대로 좋다」로
읽습니다. 문장에 세 가지는 넣지 말아 주십시오.

- **숫자를 넣지 마십시오.** 같은 등급이면 모든 선수가 같은 문장을 받습니다 —
  「약 16cm」를 적으면 그 구간의 모든 영상이 **재지도 않은 수치**를 달고 나갑니다.
- **경기 이야기를 넣지 마십시오**(「10경기 연속」·「활동량이 많고」). 이 분석이
  본 것은 **영상 한 편의 자세**뿐입니다.
- **그 항목 하나만** 말해 주십시오. 총평과 등급 표기는 화면이 따로 붙입니다.

「이 문장은 아예 빼는 게 낫다」도 답으로 받습니다.

## 1. 디딤발 위치

> 인사이드 패스는 디딤발이 목표 방향을 겨눈다. 슈팅보다 공에 바짝 붙여 딛어야 발 안쪽 면이 공 중심을 정확히 민다.

| 등급 | 기준 (참고용 — 이 종이의 질문 아님) | 칭호 | 카드 문장 | 🖊 고치실 문장 |
|---|---|---|---|---|
| **잘함** | 임팩트 시 디딤발과 공의 수평 간격이 어깨너비 0.4배 이내(약 16cm) | 방향을 잡은 디딤발 | 디딤발로 방향을 잡습니다 |  |
| **보통** | 0.4~0.75배(약 16~30cm) | 빗나간 디딤발 | 디딤발 조준이 빗나갑니다 |  |
| **아쉬움** | 0.75배 초과(약 30cm 초과) | 멀리 놓인 디딤발 | 디딤발을 공에서 멀리 둡니다 |  |

---

## 2. 차는 다리 뻗기

> 패스는 짧은 스윙으로 민다. 슈팅처럼 무릎을 끝까지 펴면 공이 뜨고 세기 조절이 안 된다.

| 등급 | 기준 (참고용 — 이 종이의 질문 아님) | 칭호 | 카드 문장 | 🖊 고치실 문장 |
|---|---|---|---|---|
| **잘함** | 임팩트 시 무릎각 120~155도 (짧게 접힌 스윙) | 짧고 정확한 스윙 | 짧고 정확하게 밀어 찹니다 |  |
| **보통** | 155~170도 | 과한 스윙 | 패스치고 스윙이 큽니다 |  |
| **아쉬움** | 170도 초과(완전 신전, 슈팅 동작) 또는 120도 미만 | 치우친 스윙 | 스윙 크기가 크게 치우칩니다 |  |

## 3. 상체 기울기

> 패스는 공을 누르는 것이 아니라 방향을 주는 동작이다. 상체를 세워 시야를 확보하되, 뒤로 젖혀지면 공이 뜬다.

| 등급 | 기준 (참고용 — 이 종이의 질문 아님) | 칭호 | 카드 문장 | 🖊 고치실 문장 |
|---|---|---|---|---|
| **잘함** | 임팩트 시 상체 전방 기울기 2~15도 | 곧게 선 상체 | 상체를 곧게 세웁니다 |  |
| **보통** | 15~25도(과도한 전방) | 숙인 상체 | 상체가 앞으로 숙여집니다 |  |
| **아쉬움** | 2도 미만(후방 젖힘) 또는 25도 초과 | 치우친 상체 | 상체 기울기가 크게 치우칩니다 |  |

## 4. 골반 돌리기

> 인사이드 면을 공에 대려면 골반이 열려야 한다. 다만 슈팅만큼 크게 돌면 방향 제어를 잃는다.

| 등급 | 기준 (참고용 — 이 종이의 질문 아님) | 칭호 | 카드 문장 | 🖊 고치실 문장 |
|---|---|---|---|---|
| **잘함** | 백스윙~임팩트 구간 골반 회전 15~35도 | 알맞게 열린 골반 | 골반을 알맞게 열어 줍니다 |  |
| **보통** | 8~15도 또는 35도 초과(과회전) | 어긋난 골반 회전 | 골반 회전이 알맞지 않습니다 |  |
| **아쉬움** | 8도 미만 | 닫힌 골반 | 골반이 거의 열리지 않습니다 |  |

## 5. 차고 난 뒤 마무리

> 패스의 팔로스루는 짧고 방향을 향한다. 슈팅처럼 크게 뻗으면 세기가 과해지고 공이 뜬다.

| 등급 | 기준 (참고용 — 이 종이의 질문 아님) | 칭호 | 카드 문장 | 🖊 고치실 문장 |
|---|---|---|---|---|
| **잘함** | 임팩트 후 고관절 굴곡 8~25도 추가 진행 (짧고 방향성 있는 마무리) | 방향을 남긴 마무리 | 마무리로 방향을 남깁니다 |  |
| **보통** | 3~8도 또는 25도 초과(슈팅에 가까운 과한 마무리) | 흘린 마무리 | 마무리가 방향에서 벗어납니다 |  |
| **아쉬움** | 3도 미만 (임팩트 직후 정지) | 끊긴 마무리 | 찬 뒤 마무리가 끊깁니다 |  |
