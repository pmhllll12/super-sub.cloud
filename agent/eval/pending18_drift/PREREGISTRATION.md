# 사전 등록 — **거부를 일으킨 것이 표류인가** (미결 18번 9회차)

**작성 2026.09.10 · 정상호 · 측정 코드보다 먼저 고정한다.**

## 8회차가 남긴 숙제 셋을 다 받는다

| 숙제 | 여기서 |
|---|---|
| **계기가 구간 길이를 쟀다** | 주 지표를 **거부가 일어난 한 프레임**에서 잰다 — 길이가 들어올 자리가 없다 |
| 대조군 관문이 공허하게 통과했다 (`YNMHMKb5Md4`, 깨끗 0장) | **최소 깨끗 장수**를 건다 |
| 사후 값(27/73)을 사전으로 승격하면 순환이다 | 🔴 **그 값을 안 쓴다.** 다른 양을 묻는다 |

## 🔴 묻는 것이 달라진다 — 「있는가」가 아니라 「**왜 거부했는가**」

8회차는 「잃은 구간에 대상이 있는가」를 기하로 물었고 **계기가 길이를
쟀다.** 여기서는 **거부의 원인**을 직접 연다.

거부는 한 줄에서 일어난다.

```python
a = app(ref, t, pick)      # ref = 갱신되며 흘러가는 참조 히스토그램
if a < TAU:                # ← 여기서 잃는다
```

`ref` 는 **표류하는** 값이고 `ah`(닻)는 **고정**이다. **그 프레임에서 둘을
나란히 보면 원인이 바로 나온다.**

| `app(ref, pick)` | `app(ah, pick)` | 읽는 법 |
|---|---|---|
| `< TAU` (거부됨) | **`≥ TAU`** | 🔴 **표류다.** 닻은 알아보는데 흘러간 `ref` 가 거부했다 → **(나)** |
| `< TAU` | `< TAU` | 닻도 못 알아본다 — 후보가 남이거나 외양이 진짜로 변했다 → **(가)** 쪽 |

🔴 **이것이 8회차 결함의 정확한 해독제다.** 거부는 **한 프레임의 사건**이라
구간 길이가 값에 들어오지 않는다. 그리고 **8회차가 안 본 양**이라 27/73을
다시 쓰는 순환이 아니다.

닻이 없다). 새 클립을 받으려면 검출 캐시부터 다시 만들어야 한다. 그래서
**클립이 아니라 「잃은 구간」을 층으로 가른다.**

| 층 | 무엇 | 크기 | 상태 |

| **B** | 과녁 **밖** 클립의 잃은 구간 | 19구간 **593프레임** | ✅ **이 질문에 처음 쓴다** |
| **C** | `O2GSaYqH8JY` | — | ✅ 풀에서 **한 번도 안 쓴 유일한 클립**(`multi=96` 으로 기준 100에 미달해 빠져 있었다) |

층 B 는 **커버가 안 무너진 클립**에서 온다. 같은 결론이 **붕괴로 고른 층과

🔴 **층 A 를 빼지 않는다.** 빼면 8회차와 이어지지 않아 무엇이 달라졌는지
못 읽는다. 대신 **층별로 따로 내고, 같은 방향일 때만 결론으로 삼는다.**

## 재는 것

궤적은 6회차 `track_gate` 그대로다. 여기 `track_reasoned` 는 같은 코드에
**기록만** 더한 사본이고, `chosen` 비트 동일을 전수로 확인한다.

| 이름 | 정의 |
|---|---|
| `ref_app` | **거부 프레임**에서 `app(ref, pick)` — 거부를 일으킨 값 |
| `anchor_app` | **같은 프레임·같은 박스**의 `app(ah, pick)` — 닻의 의견 |
| `run_anchor_best` | 구간의 프레임마다 `max app(ah, cand)`, 그 **중앙값** |
| `reacq_linked` | 구간이 **재획득으로 끝났는가** — 끝났으면 트래커 자신이 닻 기준으로 「대상이다」라고 말한 것이다 |
| `clean_med` | 대조군 — 깨끗한 프레임(**닻 제외**)의 `app(ah, chosen)` 중앙값 |

**문턱은 `TAU`(0.6) 하나다.** `RESCUE_IOU` 는 안 쓴다 — 8회차에서 길이에
오염된 그 축이라 **주 지표에서 뺀다.**

### 🔴 이 회차의 새 상수는 하나다

```
MIN_CLEAN = 20      # 대조군 관문의 최소 깨끗 장수 (닻 제외)
```

8회차에서 `YNMHMKb5Md4` 가 **0장**으로 관문을 공허하게 통과했다. 중앙값이
뜻을 가지려면 자릿수가 필요하다. **20을 고른 이유**: 과녁 7건의 깨끗 장수가
0·17·49·85·103·115·126 이라 **0과 17 사이 어디를 잘라도 같은 한 건만
빠진다** — 이 표본에서 결론이 값 선택에 안 흔들린다. 🔴 **결과를 보고 고르지
않았다**(장수는 8회차 출력에 이미 있고, 분류 결과와 무관하다).

## 🔴 판정 기준 — 결과를 보기 전에 고정한다

| | 기준 |
|---|---|
| **A** 자기 검사 | `chosen` 이 6회차 `track_gate` 와 **비트 동일** |
| **B** 대조군 관문 | `clean_med ≥ TAU` **그리고** 깨끗 장수 `≥ MIN_CLEAN` 인 클립만 판정에 쓴다. 남는 클립이 층 A·B 각각 **3건 미만이면 판별불가** |
| **C** 층 일치 | 층 A 와 층 B 의 **다수 쪽이 같아야** 한다. 갈리면 **판별불가** |

| **E** 결론 임계 | 다수 쪽이 거부 사건의 **70% 이상** (8회차와 같은 폭) |

| | 조건 | 뜻 |
|---|---|---|
| **(나) 표류다** | `ref_app < TAU ≤ anchor_app` 가 **70%+**, 양 층에서 | 뿌리는 **`ref` 갱신**이다. 처방 자리가 3회차로 돌아간다 |
| **(가) 닻도 모른다** | `anchor_app < TAU` 가 **70%+**, 양 층에서 | 표류가 아니다. 후보가 남이거나 외양이 진짜로 변했다 |
| **(다) 판별불가** | 위 둘 다 아니거나 · 층이 갈리거나 · B 가 안 서거나 · **D 가 걸리면** | 갈래를 **열어 둔다** |

## 🔴 하지 않는 것

- **`src/` 를 안 고친다.** 읽기만 한다 — 추적을 한 비트도 안 바꾼다
- **앞 회차 스크립트를 안 고친다.** import 만 한다
- **처방을 내지 않는다.** 이 회차의 산출물은 **원인 표 하나**다
- 🔴 **8회차의 27/73 을 안 쓴다.** 그 값을 보고 세운 기준은 같은 표본에서
  순환이라, 이 회차는 **다른 양**을 묻는다
- 🔴 **`RESCUE_IOU` 를 주 지표에 안 쓴다.** 길이에 오염된 축이다
- 🔴 **`app` 을 「대상인가」의 정답으로 승격하지 않는다.** 대리 지표다.
  말할 수 있는 것은 **「닻이 알아보는가」**까지이고, 「진짜 그 사람인가」는
  라벨이 있어야 한다

## 함께 보고할 것 (판정에 쓰지 않는다)

1. **계기 검사 전체** — `anchor_app` 을 구간 길이·후보 수·닻 거리로 층화.
   D 는 길이 하나만 걸지만 셋 다 낸다
2. `reacq_linked` 비율 — 재획득으로 끝난 구간은 **대상이 돌아왔거나 내내
   있었다**는 뜻이라 (나)에 무게
3. `ref_app` 과 `anchor_app` 의 차 분포 — 표류의 **크기**다
4. 거부까지 걸린 프레임 수(닻에서 거부까지) — 표류가 원인이면 **누적 시간에
   따라** 커져야 한다
