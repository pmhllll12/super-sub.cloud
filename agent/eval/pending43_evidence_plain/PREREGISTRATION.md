# 사전 등록 — 근거 문장에서 **코드 심벌**을 없앤다 (미결 `ho` 43번 ㉱, 1회차)

작성 2026.09.11 · **구현 전에 굳힌다.**

## 실물 결함 — 추측이 아니다

2026-09-11 실서버 저널에 그대로 나왔다:

```
2등급  차는 다리 뻗기
  측정값 swing_knee_angle_at_impact=151.6로 임팩트 직전 무릎각이
  140~165도 범위 내에 있어 신전 여유가 적절히 유지되었다.
```

## 🔴 결함이 **둘**이고, 이번 회차는 **하나만** 본다

| 새는 것 | 어디서 | 이번에 |
|---|---|---|
| **코드 심벌** `swing_knee_angle_at_impact` | `build_prompt` 가 `band_metric=값` · 앵커 `measured` · `metrics` 를 **JSON 그대로** 넣는다 | ✅ **고친다** |
| **구간 숫자** `140~165도` | 루브릭 `grades[g]` 문구가 구간을 품고 있다 | 🔴 **안 고친다** — 미결 23번이 이미 진단했고 처방(숫자 없는 수준 설명)이 **스키마를 늘려 지도자 검수(2·34번)에 묶여 있다** |

**둘을 한 회차에 섞지 않는다.** 앞엣것은 검수와 무관하고 오늘 고칠 수 있으며,
뒤엣것은 임계값 문구라 검수 대상이다. 섞으면 검수를 기다리느라 오늘 고칠 수
있는 것까지 멈춘다.

## 고치는 방법 — 프롬프트에서 빼면 베낄 수 없다

`build_prompt` 의 docstring 이 이미 같은 논리를 쓴다: **「프롬프트에 없는
숫자는 베껴 쓸 수 없다」.** 심벌도 같다. 코드 이름을 사람이 읽는 **라벨**로
바꾼다 — 정본은 `contracts/metric_definitions.yaml` 의 `label` 이고,
`test_metric_definitions.py::test_every_rubric_metric_is_declared` 가 **모든
루브릭 지표가 거기 선언돼 있음을 이미 보장**한다(빠질 수 없다).

🔴 **`unit` 은 붙이지 않는다.** `follow_through_duration_frames` 의 선언 단위가
`s` 인데 **실제 features 값은 프레임**이다(초 환산은 봉투의
`frame_metrics_seconds` 가 따로 싣는다, E-3). 단위를 붙이면 **「12초」라고
지어내게 된다.** 라벨만 바꾸는 것이 이번 범위다.

## 합격 기준 — 숫자를 먼저 박는다

| | 기준 |
|---|---|
| **A** | 살아 있는 전 루브릭 × 전 항목 × 전 등급의 `build_prompt` 산출에 **지표 코드 문자열이 0건**. 🔴 결정론적이라 LLM 없이 잰다 |
| **B** | 같은 산출에 **라벨이 있을 것** — 코드만 지우고 대신 아무것도 안 넣는 것을 막는다 |
| **C** | 🔴 **점수가 비트 동일**. `build_prompt` 는 근거 **문장**만 만들고 등급은 `grade_for` 가 정한다. 하나라도 바뀌면 B-6 재실행이라 그 자체가 불합격 |
| **D** | 기존 검사 전부 통과 (`uv run pytest tests/ -q`) |

## 안 하는 것

- 🔴 **「코칭 문장」으로 넓히지 않는다.** 「더 나은 설명」은 정답이 없어 판정이 안 된다
- 🔴 **등급·구간을 문장에 되돌리지 않는다** (23·24번). 등급 맥락은
  `breakdown[]` 의 `title`·`title_earned`·`band` 가 싣는다
- 루브릭 `grades[g]` 문구 손대기 — 위 표대로 검수 대상이다
- 모델·프롬프트 어투 손질 — 이번 회차는 **심벌 유출** 하나다

## 🔴 계기 검사

1. **이 양이 내가 묻는 것인가.** 재는 것은 **프롬프트에 심벌이 있는가**이지
   **모델 출력에 심벌이 있는가**가 아니다. 둘은 다르다 — 프롬프트에 없어도
   모델이 지어낼 수는 있다. **다만 관측된 유출은 전부 프롬프트를 베낀 것**이고,
   출력을 재려면 LLM 회차가 필요하다. 그건 2회차로 남긴다.
2. **이 표본이 내가 묻는 대상인가.** 전 루브릭 × 전 항목 × 전 등급 **전수**라
   표본 문제가 없다(지금 축구 2개 × 11항목 × 3등급).
