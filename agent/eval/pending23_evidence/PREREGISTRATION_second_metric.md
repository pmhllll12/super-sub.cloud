# 사전 등록 — **비밴드 지표가 문장의 방향을 끌고 가는가** (미결 23번)

**코드에 손대기 전에 커밋한다.** 결과를 보고 기준·예측을 고치지 않는다.

🔴 **조사 회차다.** `src/`·`rubrics/` 를 고치지 않는다. 고칠지 말지는 **재고
나서** 정한다.

## 1. 왜 이 회차인가

가-3 뒤 방향 오독 **7건 중 4건이 `follow_through` 한 항목**에 몰렸고, 실패
형태가 같다 — **밴드 지표가 아닌 두 번째 지표로 반대 방향을 주장한다.**

> 굴곡 **4.8도**(= 「조금밖에 안 나갔다」 조각)인데
> *"**지속 시간이 길어져** 슈팅처럼 과도하게 뻗은 느낌이 있다"*

`follow_through` 는 `measured_by` 가 둘인 **유일한 항목**이다
(`swing_hip_flexion_after_impact_deg` = 밴드 지표 · `follow_through_duration_frames`).

## 2. 🔴 먼저 의심할 것은 제품이 아니라 **계기**다

평가 스크립트가 밴드 지표가 아닌 값을 **상수 10.0 으로** 채운다
(`football_evidence.py` 의 `features.setdefault(code, 10.0)`).

| | |
|---|---|
| 실측 분포 | `phaseA_features.json` 113건 — 최소 **1** · 중앙 **4** · 사분위 **2~11** · 최대 126 |
| 프롬프트의 앵커 | 잘함 **4프레임** · 아쉬움 **1프레임** |
| 채워 넣은 값 | **10.0** — 앵커 어느 것보다 크고 실측 상위 사분위다 |

즉 **모든 문장이 「지속 시간이 길다」를 보고 있었다.** 등급과 무관하게, 매번,
같은 방향으로. 🔴 **이 표본으로는 「제품이 그런다」를 말할 수 없다.**

미결 45번 1회차·52번 1회차와 같은 형태다 — **내 앞 단계가 맞게 돌고 있는가.**

## 3. 무엇을 재는가

밴드 지표를 **고정**하고 두 번째 지표만 **실측 분포의 세 수준**으로 바꿔 가며
같은 질문을 던진다. 문장의 방향이 따라 움직이면 **두 번째 지표가 끌고 가는
것**이고, 안 움직이면 **10.0 이 범인**이었다.

| | |
|---|---|
| 항목 | `follow_through` 2루브릭(인스텝·인사이드 패스) |
| 밴드 값 | 등급마다 **조각마다** 2점 (가-3 과 같은 방식) |
| 두 번째 지표 | **1 · 4 · 11 프레임** (실측 최소 · 중앙 · 상위 사분위) |
| 표본 | 밴드 값마다 3번 → 약 **36~48문장** |

## 4. 판정 — 🔴 **합격·불합격이 아니라 측정이다**

이 회차는 **고치지 않는다.** 그래서 합격선을 두지 않고, 아래를 답한다.

| | 무엇을 답하는가 |
|---|---|
| **Q1** | 두 번째 지표 값에 따라 **방향 오독 건수가 달라지는가** |
| **Q2** | 달라진다면 **어느 쪽으로** — 값이 클 때 「과하다」로 기우는가 |
| **Q3** | 🔴 **등급이 한 건이라도 바뀌는가** (밴드 지표만 정하므로 **0이어야 한다**) |

방향 오독은 **사람이 읽는다.** 🔴 AI 판독이라 정답으로 승격하지 않는다
(`agent/CLAUDE.md`). 판정은 파일로 남겨 사람이 다시 읽게 한다.

## 5. 짝 기준 — 결과 전에 박는 예측

| | 예측 | 왜 |
|---|---|---|
| **P-1** | **1프레임**에서는 「과하다/슈팅처럼」류 오독이 **0 이 된다** | 앵커의 「아쉬움」이 1프레임이라, 짧다는 신호가 앵커와 맞는다 |
| **P-2** | **11프레임**에서 짧은 굴곡값 문장이 **「길다/과하다」로 간다** | 가-3 에서 10.0 으로 본 그대로여야 한다. 재현이 안 되면 **10.0 탓이 아니라 다른 것**이다 |
| **P-3** | 등급 변경 **0건** | 등급은 `bands` 가 밴드 지표 하나로 정한다. 🔴 **하나라도 바뀌면 그게 이 회차의 제일 큰 결과다** |

🔴 **P-1 이 이 회차의 계기다.** 1프레임에서도 「과하다」가 나오면 두 번째
지표 탓이 아니고, 내 기전 설명이 틀린 것이다.

## 6. 하지 말 것

  지표를 흔든다). 이 회차는 **그 항목 안에서만** 말한다
