# 사전 등록 — I: **앵커 문장이 구간이 아니라 자세를 말하게 한다** (미결 23번)

**루브릭에 손대기 전에 커밋한다.** 결과를 보고 기준·예측을 고치지 않는다.

## 1. 🔴 **본보기가 규칙을 어기고 있다**

프롬프트는 모델에게 **「등급 번호와 기준 구간은 쓰지 마세요」**라고 시킨다.
그런데 **앵커 문장 자신이 그것을 쓴다**:

| 자리 | 앵커 문장 |
|---|---|
| `instep/plant_knee_flexion` g2 | *"디딤발 무릎각 158도로 **기준 범위 중앙**"* |
| `instep/swing_knee_extension` g2 | *"무릎각 152도로 **기준 범위 중앙**, 신전 여유 확보"* |
| `instep/trunk_lean` g2 | *"상체 전방 기울기 12.4도로 **기준 범위 내**"* |
| `instep/hip_rotation` g1 | *"회전 범위 19.8도로 **중간 구간**"* |
| `instep/follow_through` g1 | *"**추가 굴곡** 22도로 **중간 구간**"* |

**넷은 자세를 아예 안 말한다.** 「구간 어디인지」만 말하고 끝난다.

그리고 **지표를 정본 라벨이 아닌 말로 부르는 자리**가 셋:

| 자리 | 앵커 문장 | 정본 라벨 |
|---|---|---|
| `inside/follow_through` g0 | *"**추가 굴곡** 1.5도로…"* | 임팩트 후 주동 고관절 굴곡 |
| `instep/follow_through` g1·g0 | *"**추가 굴곡** 22도·8.3도로…"* | 〃 |

🔴 **이 둘이 실제로 문장에 새고 있다는 관측이 이미 있다:**

- **D 회차**: `instep/trunk_lean` **23.5**(감점)가 *"**기준 범위 내**"* 라고 써서
  오독으로 셌다 — **앵커가 가르친 말이다**
- **H 회차**: `follow_through` **79.2·125.8** 이 *"**추가 굴곡이 부족해**"* 로
  남았고, 「추가 굴곡」이 프롬프트에 나오는 자리가 **[아쉬움] 앵커 하나뿐**이다

전수 조사: 앵커 **41개 중 판정 메타언어를 쓰는 것 5개**(「회전 범위」는 지표
이름, 「가속 구간」은 동작 서술이라 뺐다) · 「추가 굴곡」 **3개**. 겹쳐서
**고칠 앵커는 7개**다.

## 2. 무엇을 바꾸는가 — **편집 규칙 둘**

| | 규칙 |
|---|---|
| **⑴** | 판정 구간을 가리키는 말(「기준 범위 …」·「중간 구간」)을 **그 등급의 `grades_plain` 이 말하는 자세 서술**로 바꾼다 |
| **⑵** | 지표를 **정본 라벨**(`contracts/metric_definitions.yaml`)이 부르는 이름으로 부른다 — 「추가 굴곡」 → 「임팩트 후 굴곡」 |

| 🔴 안 건드리는 것 | |
|---|---|
| **앵커의 `measured` 값** | **한 글자도 안 바꾼다.** 평가가 채우는 값의 출처다(A 회차). 값을 바꾸면 기준선이 흔들린다 — **문장만 바꾸면 안 흔들린다**(H 에서 확인·정정) |
| **나머지 34개 앵커** | 위 두 규칙에 안 걸리는 것은 **그대로 둔다.** 전부 다시 쓰면 F 의 P-5 처럼 **무엇 덕인지 못 가린다** |
| 「슈팅」·「짧」 | 🔴 **안 건드린다** — **취지·수준 문구에도 있어** 앵커만 고쳐도 안 없어진다. 고치면 이 회차가 무엇을 쟀는지 흐려진다 |
| 취지 · 수준 문구 · `bands` · 가중치 · 임계값 | 그대로 — **B-6 재실행 없음** |

### 🔴 루브릭 문구를 내가 고쳐도 되는가

루브릭의 `titles`·`card_lines`·앵커 문구는 원래 **지도자 검수 대상**이다
(미결 2번은 **검수 없이 가기로** 정해졌다). 이 회차는 그 결정과 **무관하게**
성립한다고 본다:

- **임계값·가중치·등급을 안 건드린다.** 점수가 한 점도 안 바뀐다
- 바꾸는 방향이 **제품이 이미 정한 규칙**(「문장에 등급·구간을 쓰지 않는다」,
  「지표는 정본 라벨로 부른다」)**에 본보기를 맞추는 것**이라, 코치가 판단할
  **기술 내용이 아니라 내부 일관성 수선**이다
- 🔴 **그래도 알린다** — 미결 항목에 박민호 님께 남긴다. 「선수에게 보이는
  말의 본보기를 담당자가 고쳤다」는 사실 자체는 알려야 한다

## 3. 판정 기준 — 결과 전에 고정

대조군은 **F**(`evidence_anchor_order.json`, 지금 제품). 방향 오독은 D 회차의
**절 단위 계기**로 읽고 **규칙을 넓히지 않는다.** 잘함 22자리는 문장 단위.

| | 기준 | 합격선 |
|---|---|---|
| **A** | R1 「등급」 낱말 | **0건** |
| **B** | R2 구간 표기 | **0건** |
| **C** | R2′ 경계 숫자 누출 | **0건** |
| **D** | R3 지어낸 수치 | **2건 이하** |
| **E** | 방향 오독 /30 | **F 의 4건보다 늘면 불합격** |
| **F** | 잘함 오독 /22 | **1건 이하** |
| **G** | 밴드값·등급이 F 와 동일 | **80/80** |
| **H** | `pytest tests/ -q` | 통과 |
| **I** | 🔴 **문장에 「기준 범위」·「중간 구간」·「추가 굴곡」** | **F 보다 늘면 불합격** (기계적으로 센다 — 판독 안 들어감) |

🔴 **기준 I 를 기계로 센다.** 정확한 어구의 출현 수라 판독이 안 들어가고,
이 회차가 겨냥한 것을 **직접** 잰다.

## 4. 짝 기준 — 결과 전에 박는 예측

| | 예측 | 왜 |
|---|---|---|
| **P-1** 🔴 | 「기준 범위」·「중간 구간」이 문장에서 **0건** | 프롬프트에서 그 말이 나오는 자리가 **앵커뿐**이었다 |
| **P-2** 🔴 | 「추가 굴곡」이 문장에서 **0건** | 〃 |
| **P-3** | 방향 오독이 **4 이하**로 유지된다 | 79.2·125.8 의 *"추가 굴곡이 부족해"* 가 사라질 수 있다 |
| **P-4** | 잘함 오독 **1 이하** | 앵커 문장이 **자세를 말하게** 되므로 칭찬 쪽이 더 선명해진다 |
| **P-5** | 등급 변경 **0/80** | 값도 `bands` 도 안 건드린다 |

🔴 **P-1·P-2 가 계기다.** 어구가 앵커에만 있었으니 빼면 **사라져야 한다.**
안 사라지면 출처가 **모델 자신**이고, 그러면 루브릭을 고쳐서 될 일이
아니라는 뜻이다 — C 회차가 「어구를 짚은 것은 가설이지 인과가 아니다」를
가르쳤고, 이번이 그 가설을 **제거로** 확인하는 자리다.

## 5. 하지 말 것

- 🔴 **`measured` 값을 안 바꾼다** (2절)
- 🔴 **규칙에 안 걸리는 앵커를 고치지 않는다** — 전부 다시 쓰면 못 가린다
- 🔴 **「슈팅」·「짧」을 안 건드린다** — 취지에도 있다
- 🔴 **임계값·가중치·`bands`·취지·수준 문구를 안 건드린다**
- 🔴 결과를 보고 **문구를 다듬어 다시 재지 않는다**
- 🔴 결과를 보고 **판정 규칙을 넓히지 않는다**
- 🔴 영어 혼입을 **같이 세지 않는다** — 한 회차에 하나씩
