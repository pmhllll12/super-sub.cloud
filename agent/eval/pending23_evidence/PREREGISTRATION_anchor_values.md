# 사전 등록 — E: **옆 등급 앵커는 측정값만 남기고 문장을 뺀다** (미결 23번)

**코드에 손대기 전에 커밋한다.** 결과를 보고 기준·예측을 고치지 않는다.

## 1. 왜 이 회차인가 — C 가 **하나만** 열어 두고 갔다

C 회차(`RESULTS_source_trace.md`)의 2×2 제거 실험에서 옆 등급 앵커를 끄니
**둘이 동시에** 일어났다:

| | 옆 등급 앵커를 끄면 |
|---|---|
| ⓐ 얻은 것 | `hip_rotation` **85.8** 의 방향이 **고쳐졌다**(C2). 방향 오독 5 → 3 |
| ⓑ 잃은 것 | **지어낸 수치 2 → 5**, 둘 다 끄니 **8**. 밴드 **경계값까지 샜다**(C3, 기준 R2′ 불합격) |

그래서 「끄는 것」은 닫았고(로드맵 4절), 남은 것이 **「좁히는 것」**이다.

🔴 **가설: 앵커 한 줄이 두 가지 일을 하고 있다.**

```
- [잘함] 골반 회전 범위 24.0도 → "골반 회전 24도로 인사이드 면이 공을 향해 열렸다"
         └─ 측정값: 「말해도 되는 숫자」의 울타리 ─┘  └─ 문장: 어투와 **방향**을 끈다 ─┘
```

**측정값이 ⓑ를 막고, 문장이 ⓐ를 일으킨다면** 둘을 갈라 측정값만 남기면
된다. **이 회차가 그 가설을 시험한다.**

## 2. 무엇을 바꾸는가

`judge.py` 의 `build_prompt` 에서 **판정 등급이 아닌 앵커**는
`→ "문장"` 을 **빼고 측정값까지만** 싣는다.

```
before                                   after
- [잘함] 회전 범위 24.0도 → "…열렸다"     - [잘함] 회전 범위 24.0도
- [보통] 회전 범위 45.0도 → "…돌렸다"     - [보통] 회전 범위 45.0도 → "…돌렸다"  ← 이번 판정
- [아쉬움] 회전 범위 5.0도 → "…닫혀…"     - [아쉬움] 회전 범위 5.0도
```

| 🔴 안 건드리는 것 | |
|---|---|
| **판정 등급·판정 조각의 앵커** | 문장까지 **그대로**. 어투 본보기가 하나는 있어야 한다 — 1회차에서 앵커를 줄였다가 잘함 문장 8건 중 4건이 무너졌다 |
| **앵커의 측정값** | 셋 다 그대로. 그것이 이 회차가 지키려는 울타리다 |
| 항목 취지 · 수준 문구 | C 에서 취지 제거는 **닫혔다**(방향 오독 2배) |
| `bands` · 가중치 · `rubrics/*.yaml` | **B-6 재실행 없음** |
| `eval/` 의 계기 | A·D 에서 고쳤다 — 기준선을 또 흔들지 않는다 |

## 3. 판정 기준 — 결과 전에 고정

대조군은 **C0**(= B 회차 산출물 `evidence_other_levels.json`). 같은 80문장
자리를 같은 계기로 다시 만든다.

🔴 **방향 오독은 D 회차의 절 단위 계기로 읽는다**(`split_clauses.py` →
`reading_*.json`). 규칙은 **바꾸지 않는다** — D 결과 2가 짚은 구멍
(「제3의 주장」·「방향을 안 말하고 문제없다고 하는 것」)도 **그때의 관례
그대로** 센다. 여기서 규칙을 넓히면 C0 과 비교가 끊긴다.

| | 기준 | 합격선 |
|---|---|---|
| **A** | R1 「등급」 낱말 | **0건** |
| **B** | R2 구간 표기 | **0건** |
| **C** | R2′ 경계 숫자 누출 | **0건** |
| **D** | 🔴 **R3 지어낸 수치** | **C0 의 2건 이하** — **이 회차의 핵심이다** |
| **E** | 방향 오독 (절 단위, 30자리) | **C0 의 5건보다 늘면 불합격** |
| **F** | 잘함 문장 오독 (22자리) | **1건 이하** (C0 가 1건) |
| **G** | 밴드값·등급이 C0 과 동일 | **80/80** |
| **H** | `pytest tests/ -q` | 통과 |

🔴 **D 가 이 회차의 안전장치다.** C2 가 방향을 고치면서 R3 를 2 → 5 로
올렸다. **「방향이 좋아졌다」만 재고 「숫자 울타리」를 안 재면 C2 를 다시
하는 것**이고, 그건 이미 닫힌 경로다.

## 4. 짝 기준 — 결과 전에 박는 예측

| | 예측 | 왜 |
|---|---|---|
| **P-1** | `hip_rotation` **85.8** 의 방향이 **고쳐진다** | C2 에서 고쳐졌고, 이 회차는 C2 와 **문장을 뺀다는 점에서 같다** |
| **P-2** 🔴 | **R3 가 2건 이하** (기준 D) | 측정값이 남으므로 울타리가 선다. **이것이 가설의 핵심이고, 틀리면 「측정값이 울타리」가 아니라는 뜻이다** |
| **P-3** | 잘함 문장 오독이 **안 늘어난다** | 수준 낱말 + 판정 등급 앵커의 문장이 눈금을 준다 |
| **P-4** | 등급 변경 **0/80** | `bands` 를 안 건드린다 |
| **P-5** | 방향 오독이 **3건 근처** | C2 가 3이었다 |

🔴 **P-2 가 계기다.** C 에서 「어구의 출처와 오류의 원인이 다르다」를 배웠고,
이번엔 **「앵커의 두 역할이 갈라지는가」**를 같은 방식으로 묻는다.
갈라지지 않으면(= R3 가 오르면) **앵커는 통째로만 쓰이는 것**이고,
85.8 은 앵커 말고 **다른 길**로 고쳐야 한다.
