# 사전 등록 — F: **앵커를 측정값 순으로 나열한다** (미결 23번)

**코드에 손대기 전에 커밋한다.** 결과를 보고 기준·예측을 고치지 않는다.

## 1. 왜 이 회차인가 — E 가 「빼는 것」을 닫았다. 남은 것은 **순서**다

| 회차 | 무엇을 했나 | 결과 |
|---|---|---|
| 1회차 | 앵커의 수준 표시를 뺐다 | 🔴 잘함 문장 8건 중 4건 붕괴 |
| C (C2·C3) | 옆 등급 앵커를 **통째로** 껐다 | 방향은 좋아졌으나 🔴 **지어낸 수치 2 → 5 → 8**, 경계 누출 |
| E | 옆 등급 앵커의 **문장만** 뺐다 | 방향 5 → 2 · R3 1건 ✅ 🔴 **잘함 1 → 6/22 붕괴, 되돌림** |

**셋 다 「덜 준다」였고 셋 다 무언가를 무너뜨렸다.** 이 회차는 **아무것도
빼지 않는다** — 같은 것을 **다른 차례로** 준다.

🔴 **C 회차가 구조를 이미 짚어 두었다**(`RESULTS_source_trace.md` 1절):

> 이 항목의 앵커 사다리는 **값에 대해 단조가 아니다**: 잘함 **24** → 보통
> **45** → 아쉬움 **5**. 「좋은 것부터」 늘어놓으면 값이 24↑45↓5 로
> 오르내린다. 그리고 측정값 **85.8 은 세 앵커 중 어느 것보다도 크다**.

**양방향 구간에서는 이 배치가 예외가 아니라 기본값이다.** 등급은 「좋음」의
차례이고 값은 「크기」의 차례인데, 두 축이 다르면 **한쪽으로 늘어놓는 순간
다른 쪽이 뒤엉킨다.** 지금은 등급 순이라 **값이 뒤엉켜 있다.**

## 2. 무엇을 바꾸는가 — **정렬 키 하나**

`build_prompt` 의 앵커 목록을 **등급 내림차순 → 밴드 지표 값 오름차순**으로.

```
before (등급 순)                         after (값 순)
- [잘함]   회전 24.0도 → "…열렸다"        - [아쉬움] 회전 5.0도  → "…닫혀…"
- [보통]   회전 45.0도 → "…돌렸다"        - [잘함]   회전 24.0도 → "…열렸다"
- [아쉬움] 회전 5.0도  → "…닫혀…"         - [보통]   회전 45.0도 → "…돌렸다"
                                          (측정값 85.8 → 사다리 끝 너머다)
```

| 🔴 안 건드리는 것 | |
|---|---|
| **문장** | **하나도 안 뺀다.** E 가 닫은 길이다 |
| **측정값 · 수준 낱말** | 줄마다 `[잘함]`·`[보통]`·`[아쉬움]` 이 그대로 붙는다 — 어느 어투가 어느 수준인지는 **낱말이** 말하지 차례가 말하지 않는다 |
| 앵커 고르기(가-3) · 항목 취지 · 수준 문구 | 그대로 |
| `bands` · 가중치 · `rubrics/*.yaml` | **B-6 재실행 없음** |

🔴 **지금 코드의 「좋은 것부터」에는 이유가 적혀 있다** — 「위 수준 목록과
같은 차례여야 짝이 보인다(1회차에서 그 짝을 잃고 2등급 문장이 무너졌다)」.
**그 우려를 기준 F 가 그대로 지킨다.** 1회차에 무너진 진짜 이유는
**수준 낱말이 사라진 것**이었고, 낱말은 이번에 안 건드린다 — 그 구분이
맞는지도 이 회차가 같이 잰다.

## 3. 판정 기준 — 결과 전에 고정

대조군은 **C0**(`evidence_other_levels.json`). 방향 오독은 **D 회차의 절 단위
계기**로 읽고 **규칙을 넓히지 않는다**. 잘함 22자리는 **C·E 와 같은 방식
(문장 단위)** 으로 읽는다 — 계기를 여기서 바꾸면 E 와 비교가 끊긴다.

| | 기준 | 합격선 |
|---|---|---|
| **A** | R1 「등급」 낱말 | **0건** |
| **B** | R2 구간 표기 | **0건** |
| **C** | R2′ 경계 숫자 누출 | **0건** |
| **D** | R3 지어낸 수치 | **2건 이하** (C0 가 2) |
| **E** | 방향 오독 (절 단위 /30) | **C0 의 5건보다 늘면 불합격** |
| **F** | 🔴 **잘함 문장 오독 /22** | **1건 이하** (C0 가 1) |
| **G** | 밴드값·등급이 C0 과 동일 | **80/80** |
| **H** | `pytest tests/ -q` | 통과 |

🔴 **기준 F 를 E 와 **똑같이** 가져간다.** E 가 거기서 떨어졌고, 이 회차의
핵심 주장이 「빼지 않았으니 안 무너진다」이기 때문이다. 무너지면 그 주장이
틀린 것이고, **차례만으로도 잘함 문장이 무너진다**는 새 사실이다.

## 4. 짝 기준 — 결과 전에 박는 예측

| | 예측 | 왜 |
|---|---|---|
| **P-1** | `hip_rotation` **85.8** 의 방향이 **고쳐진다** | 값 순이면 사다리가 5→24→45 로 단조이고, 측정값 85.8 이 **그 끝 너머**다. 가장 가까운 앵커가 45 [보통] *"지나치게 많이 돌렸다"* 다 |
| **P-2** 🔴 | 잘함 문장 오독 **1건 이하** (기준 F) | 문장을 하나도 안 뺐다. **E 가 무너진 것이 「뺐기 때문」이지 「차례 때문」이 아니라면** 여기서 버틴다 |
| **P-3** | R3 **2건 이하** | 측정값도 문장도 다 남는다 |
| **P-4** | 등급 변경 **0/80** | `bands` 를 안 건드린다 |
| **P-5** | 🔴 **달라지는 문장이 양방향 자리에 몰린다** | 한 방향뿐인 항목은 등급 순과 값 순이 **같거나 뒤집힌 것뿐**이라 사다리가 이미 단조다 |

🔴 **P-2 가 계기다.** E 의 실패 원인을 「덜 줘서」로 읽었는데, 그것이
맞는지를 **주는 양을 그대로 둔 채** 확인한다. 여기서도 무너지면 내 진단이
틀린 것이고 **그게 더 중요한 결과다** — C·B 에서 두 번 그랬다.

## 5. 하지 말 것

- 🔴 **문장을 빼지 않는다** — E 에서 닫혔다. 「값만 남기기」도 다시 재지 않는다
- 🔴 **수준 낱말(`[잘함]`…)을 빼지 않는다** — 1회차의 대가
- 🔴 **앵커 고르기(가-3)를 건드리지 않는다** — 이번에 바꾸는 것은 **차례**뿐이다
- 🔴 **`bands`·가중치·루브릭 파일을 안 건드린다**
- 🔴 결과를 보고 **판정 규칙을 넓히지 않는다**(D 결과 2의 구멍 포함)
- 🔴 **루브릭 앵커 문장을 손보지 않는다** — E 가 남긴 *"기준 범위 내"* 문제는
  별도 회차다. 앵커를 고치면 `eval/` 의 채우는 값이 바뀌어 A 기준선이 흔들린다
- 🔴 영어 혼입·판정 메타언어 누출을 **같이 세지 않는다**
