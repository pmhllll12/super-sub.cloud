# 사전 등록 — A: **채워 넣는 값을 상수에서 앵커 값으로** (미결 23번)

**코드에 손대기 전에 커밋한다.** 결과를 보고 기준·예측을 고치지 않는다.

## 1. 무엇을 고치는가

평가 스크립트가 밴드 지표가 **아닌** 지표를 상수 `10.0` 으로 채운다
(`football_evidence.py`: `features.setdefault(code, 10.0)`).

앞 회차가 그것이 **문장을 끌고 갔음**을 쟀다 — 실측 중앙은 **4**인데 `10.0`
이 앵커 스케일(잘함 4·아쉬움 1)을 넘어 **「길다」로 읽혔고**, 굴곡 4.8 의
오독이 지속 1·4 에서는 **안 났다**.

🔴 **이건 제품이 아니라 계기의 결함이다.** 고치는 것은 `eval/` 뿐이다.

## 2. 무엇으로 바꾸는가 — **그 등급 앵커의 값**

| 후보 | 왜 안 고르나 |
|---|---|
| 실측 중앙값 하나(4.0) | **또 상수다.** 등급과 무관하게 같은 신호를 준다 — `10.0` 과 같은 형태의 결함이고 크기만 작다 |
| 실측 분포에서 무작위 | **재현이 깨진다.** 같은 코드가 같은 문장을 내야 이 항목의 앞선 회차들과 말이 된다 |
| **✅ 그 등급 앵커의 값** | 루브릭이 **이미 등급마다 적어 둔 값**이다. 실측에서 왔고, 등급과 어긋나지 않으며, 결정적이다 |

앵커가 여럿이면 **가-3 과 같은 규칙** — 밴드 값이 앉은 조각의 앵커를 쓴다.

🔴 **이것이 재지 **못하게** 되는 것을 밝혀 둔다.** 두 번째 지표가 등급과
**어긋날 때** 문장이 어떻게 되는지는 이 표본으로 더 못 잰다 — 앞 회차
(`RESULTS_second_metric.md`)가 그 질문을 이미 따로 쟀고, **그 역할을 이
표본에 겸하게 두는 것이 지금 문제**이기 때문이다. **계기는 중립이어야 한다.**

## 3. 함께 고치는 것 하나

🔴 **가-3 에서 내가 더한 앵커가 두 번째 지표를 빠뜨렸다**
(`inside_pass/follow_through` g1 의 `5.0도`). 그러면 위 규칙이 채울 값이 없다.
**그 앵커에 지속 시간을 더하고**, 앵커가 `measured_by` 를 전부 적었는지
**검사로 묶는다.**

## 4. 판정 기준 — 결과 전에 고정

| | 기준 | 합격선 |
|---|---|---|
| **A** | R1 「등급」 낱말 | **0건** |
| **B** | R2 구간 표기 | **0건** |
| **C** | R2′ 경계 숫자 누출 | **0건** |
| **D** | 방향 오독 (사람이 읽는다) | 보고만 · **가-3 의 7건보다 늘면 불합격** |
| **E** | 판정 입력 중 **밴드 값·등급**이 가-3 과 동일 | **80/80** |
| **F** | 앵커가 `measured_by` 를 다 적었는지 검사가 무는가 | 되돌려 확인 |
| **G** | `pytest tests/ -q` | 통과 |

## 5. 짝 기준 — 결과 전에 박는 예측

| | 예측 | 왜 |
|---|---|---|
| **P-1** | 방향 오독 **5건 이하** | 가-3 의 7건 중 **4.8·6.2 두 자리가 계기 탓**이었음을 쟀다. 그 둘이 사라지면 5다 |
| **P-2** 🔴 | **79.2·125.8 은 여전히 틀린다** | 지속 시간과 **무관**함을 1·4·11 셋에서 쟀다. 이번 변경이 **안 닿는다.** 고쳐지면 내 기전 설명이 틀린 것이다 |
| **P-3** | 등급 변경 **0/80** | 채우는 값은 `bands` 를 안 건드린다 |
| **P-4** 🔴 | **`follow_through` 가 아닌 68문장은 가-3 과 문장이 한 글자도 안 다르다** | 그 문장들은 프롬프트가 **하나도 안 바뀌고** 디코딩이 greedy(`temperature=0`)다. **다르면 판정이 재현되지 않는다는 뜻이고, 그것이 이 회차의 제일 큰 결과다** |

🔴 **P-4 를 넣는 이유**: 앞 회차 결과에 「문장 생성이 흔들린다」고 적었다가
**같은 조건이 아니었음을 깨닫고 정정했다**(10.0 을 안 쟀는데 11 과 견줬다).
흔들림은 **재서 말할 것**이지 짐작할 것이 아니다. 이번엔 잰다.

## 6. 하지 말 것

- 🔴 **`src/`·`rubrics/` 의 문구를 안 고친다.** 고치는 것은 `eval/` 의 채우는
  값과, 위 3절의 **빠진 앵커 값 하나**뿐이다
- 🔴 결과를 보고 **채우는 규칙을 바꿔 다시 재지 않는다**
- 🔴 **가-2·가-3 의 숫자를 고쳐 쓰지 않는다** — 그 회차들은 `10.0` 위에서 났고
  **그대로 기록으로 남긴다.** 이 회차부터가 새 기준선이다
