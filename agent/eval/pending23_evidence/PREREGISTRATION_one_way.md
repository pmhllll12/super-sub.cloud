# 사전 등록 — H: **한 방향으로만 말하게 한다** (미결 23번)

**코드에 손대기 전에 커밋한다.** 결과를 보고 기준·예측을 고치지 않는다.

## 1. 남은 오독 넷이 **같은 모양**이다

F 뒤 방향 오독이 **4/30** 이고, 넷 다 **한 문장 안에서 양쪽 방향을 다 말한다**:

| 자리 | 맞는 방향 | 문장 (🔴 = 오독 절) |
|---|---|---|
| `hip_rotation` **129.2** | 지나치게 많이 돌린다 | 지나치게 많이 열렸다. 🔴 *"인사이드 면이 공을 효과적으로 차지는 데는 **도움이 되지만**"* |
| `follow_through` **79.2** | 마무리가 슈팅처럼 크다 | 과도하게 뻗은 마무리다. 🔴 *"**추가 굴곡이 부족해**"* |
| `follow_through` **125.8** | 마무리가 슈팅처럼 크다 | 🔴 *"차는 다리가 **짧고**"* / 슈팅처럼 뻗었다 / 🔴 *"**추가 굴곡이 부족해**"* |
| `instep/trunk_lean` **26.5** | 공 위로 조금 깊이 숙인다 | 공 위로 조금 깊이 숙이면서 / 기준 범위를 벗어나 / 🔴 *"약간 과도하게 **뒤로 젖혀졌다**"* |

🔴 **G 결과의 서술을 정정한다.** 거기 「넷 다 **마지막 절**에서 뒤집는다」고
적었는데 **125.8 은 첫 절부터 틀렸다.** 맞는 일반화는 **「한 문장 안에서
양쪽을 다 말한다」**이지 절의 위치가 아니다.

**넷 다 양방향 자리다**(G 에서 확인). 반대 조각의 말이 프롬프트 어딘가에
있어서가 아니라 — C·E·F 에서 그 경로들을 이미 좁혔다 — **모델이 스스로
균형을 잡으려 한다**는 쪽이 지금 남은 설명이다. *"…데는 도움이 되지만"* 이
그 모양이다.

## 2. 무엇을 바꾸는가 — **끝맺음에 한 줄**

지금 끝맺음:

```
위 [보통] 예시와 같은 어투로 씁니다. 등급 번호나 기준 구간은 쓰지 마세요 —
측정값을 짚어 자세가 어땠는지 서술하고, 무엇을 고치면 되는지 한 마디 붙입니다.
```

여기에 **한 줄을 더한다**:

```
자세가 어느 쪽으로 치우쳤는지는 **한 방향으로만** 말합니다 — 반대쪽으로도
그렇다는 말을 덧붙이지 마세요.
```

| 🔴 안 건드리는 것 | |
|---|---|
| **반대 방향을 이름으로 부르지 않는다** | 「덜 열렸다」·「짧다」 같은 말을 프롬프트에 넣으면 **모델이 그것을 베낀다** — C 회차가 「프롬프트에 있는 말은 언젠가 새어 나온다」를 두 번 보였다. 「반대쪽」이라는 **추상어**만 쓴다 |
| 앵커 · 앵커 차례(F) · 항목 취지 · 수준 문구 | 그대로 |
| `bands` · 가중치 · `rubrics/*.yaml` | **B-6 재실행 없음** |

## 3. 판정 기준 — 결과 전에 고정

🔴 **대조군을 F 로 한다** (`evidence_anchor_order.json`). F 가 지금 제품이고,
이 회차는 그 위에 얹는 변경이다. C0 는 참고로만 적는다.

방향 오독은 **D 회차의 절 단위 계기**로 읽고 **규칙을 넓히지 않는다.**
잘함 22자리는 C·E·F 와 같은 방식(문장 단위)으로 읽는다.

| | 기준 | 합격선 |
|---|---|---|
| **A** | R1 「등급」 낱말 | **0건** |
| **B** | R2 구간 표기 | **0건** |
| **C** | R2′ 경계 숫자 누출 | **0건** |
| **D** | R3 지어낸 수치 | **2건 이하** |
| **E** | 🔴 **방향 오독 /30** | **2건 이하** (F 가 4) |
| **F** | 잘함 문장 오독 /22 | **1건 이하** (F 가 1) |
| **G** | 밴드값·등급이 F 와 동일 | **80/80** |
| **H** | `pytest tests/ -q` | 통과 |

🔴 **기준 D 를 F 의 0 이 아니라 2 로 둔다.** F 의 R3 0건은 **G 회차에서
출처 미상으로 남았다**(한 방향 자리에서도 없어졌다). **모르는 것을 바닥으로
삼으면 그 위에 쌓는 것도 모르는 것이 된다.** C0 수준(2)을 지키는 것으로 한다.

🔴 **기준 E 를 「악화 금지」가 아니라 「절반 이하」로 박는다.** 남은 넷이
**전부 같은 모양**이고 이 변경이 **그 모양을 정면으로 겨냥**하기 때문이다.
겨냥한 것을 못 맞히면 **진단이 틀린 것**이고, 그때 「그래도 안 나빠졌다」로
넘어가면 안 된다.
