# 사전 등록 — B: **판정 등급이 아닌 수준 문구를 프롬프트에서 뺀다** (미결 23번)

**코드에 손대기 전에 커밋한다.** 결과를 보고 기준·예측을 고치지 않는다.

## 1. 남은 5건의 출처를 프롬프트에서 짚었다

A 뒤 방향 오독이 **5/30** 이고, **전부 옆 등급 문구를 끌어온다.** 어디서
오는지 프롬프트를 찍어 확인했다:

| 자리 | 모델이 쓴 말 | 프롬프트의 어디에 그 말이 있나 |
|---|---|---|
| `follow_through` **79.2 · 125.8** | *"팔로스루가 **짧고** 방향을 유지하며"* | **[잘함] 수준 문구** — *"찬 뒤 다리가 **짧게**, 방향을 남기며 멈춘다"* |
| `hip_rotation` **85.8** | *"인사이드 면을 … **부족**하다"* | **[아쉬움] 수준 문구** — *"인사이드 면이 공에 **닿지 않는다**"* |
| `trunk_lean` **29.8 · 32.2** | *"과도하게 **뒤로 젖혀**"* | 🔴 **수준 문구에도 앵커에도 없다.** **항목 취지**에만 있다 — *"**뒤로 젖혀지면** 공이 뜬다"* |

🔴 **셋이 같아 보이지만 출처가 둘이다.** 이 회차가 손대는 것은 **수준 문구**
뿐이라, 마지막 줄은 **안 고쳐져야 한다.**

## 2. 무엇을 바꾸는가

**수준 목록에 판정 등급 하나만 싣는다.**

```
이 항목의 수준 (좋은 것부터):        →   이번 판정 수준:
- [잘함] …                                - [아쉬움] 상체를 공 위로 깊이 숙인다
- [보통] …
- [아쉬움] …  ← 이번 판정
```

🔴 **앵커는 셋 다 그대로 둔다.** 1회차에서 앵커의 수준 표시를 뺐다가 **2등급
문장 8건 중 4건이 무너졌다** — 어느 어투가 어느 수준인지는 **앵커가** 짝지어
준다. 수준 문구를 빼도 `[잘함]`·`[아쉬움]` 앵커가 남아 **눈금은 보인다.**

| 🔴 안 건드리는 것 | |
|---|---|
| **항목 취지(`rationale`)** | 이 회차가 재려는 것과 **다른 출처**다. 같이 고치면 무엇 덕인지 못 가린다 |
| 앵커 · 루브릭 문구 · `bands` · 가중치 | **B-6 재실행 없음** |
| `eval/` 의 채우는 규칙 | A 에서 막 고쳤다 — 기준선을 또 흔들지 않는다 |

## 3. 판정 기준 — 결과 전에 고정

| | 기준 | 합격선 |
|---|---|---|
| **A** | R1 「등급」 낱말 | **0건** |
| **B** | R2 구간 표기 | **0건** |
| **C** | R2′ 경계 숫자 누출 | **0건** |
| **D** | 방향 오독 (사람이 읽는다) | 보고만 · **A 의 5건보다 늘면 불합격** |
| **E** | 🔴 **잘함 등급 문장의 방향 오독** | **0건 유지** — 1회차의 대가가 재현되면 불합격 |
| **F** | 밴드값·등급이 A 와 동일 | **80/80** |
| **G** | `pytest tests/ -q` | 통과 |

🔴 **E 가 이 회차의 안전장치다.** 「빼면 좋아진다」만 재고 **빼서 잃는 것**을
안 재면, 1회차에서 이미 한 번 밟은 자리를 또 밟는다.

## 4. 짝 기준 — 결과 전에 박는 예측

| | 예측 | 왜 |
|---|---|---|
| **P-1** | 방향 오독 **2건 이하** | 5건 중 **셋**(79.2·125.8·85.8)의 출처가 수준 문구다. 사라지면 2다 |
| **P-2** 🔴 | **`trunk_lean` 29.8·32.2 는 안 고쳐진다** | 출처가 **항목 취지**라 이번 변경이 **안 닿는다.** 고쳐지면 내 출처 추적이 틀린 것이고, **그게 더 중요한 결과다** |
| **P-3** | 잘함 문장 오독 **0 유지**(기준 E) | 앵커가 남아 눈금을 준다 |
| **P-4** | 등급 변경 **0/80** | 프롬프트는 `bands` 를 안 건드린다 |

🔴 **P-2 가 계기다.** 가-3·앞 회차에서 「안 고쳐질 자리」를 미리 짚은 것이
두 번 다 맞았다. 이번에도 틀리면 **출처를 잘못 읽고 있다**는 뜻이다.

## 5. 하지 말 것

- 🔴 **항목 취지를 같이 고치지 않는다** — 섞으면 무엇 덕인지 못 가린다.
  고칠 값이면 **다음 회차 + 새 사전 등록**이다
- 🔴 **앵커를 줄이지 않는다** (1회차의 대가)
- 🔴 결과를 보고 **수준 문구를 다듬어 다시 재지 않는다**
- 🔴 **`bands`·가중치를 안 건드린다**
