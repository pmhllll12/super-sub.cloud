# 사전 등록 — **돌아온 상자가 잃기 직전 상자와 이어지는가** (미결 18번 10회차)

**작성 2026.09.10 · 정상호 · 측정 코드보다 먼저 고정한다.**

## 9회차가 남긴 갈래를 받는다

9회차 판정은 **(가) 닻도 못 알아본다 96%** 였다. 그 문장이 아직 **두 사정을
안 가른다.**

| | 뜻 | 그러면 무엇을 하는가 |
|---|---|---|
| **(i) 후보가 진짜 남이다** | 대상이 가려졌거나 화면을 나갔고, 구간에 남은 상자는 다른 사람이다 | 🔴 **커버리지 붕괴는 결함이 아니다.** `None` 이 정직한 답이고, 남는 일은 추적이 아니라 **알리기**(이미 `source` 를 낮춰 두었다). 미결 18번의 추적 갈래를 **닫는다** |
| **(ii) 대상인데 그동안 안 닮아 보인다** | 가림·조명·스케일로 색 히스토그램이 무너졌다 | 뿌리는 **닻 기술자**다. 처방은 **더 강한 외양 표현**이고, 그건 새 의존(모델·GPU)을 부르는 별도 회차다 |

**어느 쪽이냐에 따라 다음 회차가 아예 다른 일이 된다.** 그래서 가른다.

## 🔴 묻는 것 — 「돌아온 자리」가 「잃은 자리」인가

재획득은 **닻 기준**으로 고른 것이라(`app(ah, cand) ≥ REACQ_TAU`) **트래커
자신이 낸 「이것이 대상이다」 선언**이다. 그 상자를 **잃기 직전의 상자**와
공간으로 이어 본다.

| 재획득 상자의 자리 | 읽는 법 |
|---|---|
| 잃기 직전 상자와 **겹친다** | 대상은 그 자리에 **있었다**. 구간의 후보 중에 대상이 있었는데 못 알아본 것이다 → **(ii)** |
| **딴 데서 나타난다** | 대상은 그 자리에 **없었다**. 구간의 상자들은 남이고, 대상은 나갔다 돌아왔다 → **(i)** |

라벨이 필요 없다 — **트래커가 스스로 찍은 두 점을 잇기만 한다.**

## 🔴 계기 검사를 규격에 먼저 박는다 (8회차 교훈)

8회차는 `cont_iou` 가 **구간이 길면 대상이 있어도 떨어지는** 양이라 판정을
버렸다. **여기도 IoU 다** — 구간이 길면 사람이 실제로 이동하므로 이어져도
안 겹친다. 그래서:

1. **주 지표는 짧은 구간에서만 낸다.** 기본 상한 **10프레임**(≈0.33초 @30fps).
   그만큼이면 사람은 자기 상자 폭만큼 못 움직인다
2. **주 층 안에서 길이와의 상관을 다시 잰다** (기준 D). 층을 잘라도 남아
   있으면 계기가 또 죽은 것이다
3. 전 구간에서 잰 값도 **함께 보고**한다 — 층화가 왜 필요했는지가 거기 보인다

### 표본이 모자라면 — **넓히는 규칙도 미리 정한다**

짧은 구간이 몇 개인지 아직 모른다. 결과를 보고 상한을 고르면 그 순간
근거가 아니게 되므로 **사다리를 미리 고정한다.**

```
SHORT_CAPS = (10, 20, 30)   # 이 순서로 내려가며 처음으로 MIN_RUNS 를 채우는 상한을 쓴다
MIN_RUNS   = 8              # 주 층에 필요한 최소 구간 수
```

🔴 **넓히는 기준은 「표본 수」 하나다** — 어느 상한에서 결론이 어떻게 나오는지는
보지 않고 정한다. 30까지 가도 8구간이 안 되면 **판별불가**로 적는다.
(모든 상한에서의 값은 **함께 보고**에 전부 낸다 — 고른 것만 내면 나머지를
숨긴 것이 된다.)

## 재는 것

궤적은 6회차 `track_gate` 그대로다. `track_linked` 는 같은 코드에 **기록만**
더한 사본이고, `chosen` 비트 동일을 전수로 확인한다(기준 A).

| 이름 | 정의 |
|---|---|
| `prev_box` | 잃기 **직전** 걸음의 상자 (`previous` — 구간 동안 갱신되지 않는다) |
| `reacq_box` | 재획득 프레임에서 닻이 고른 상자 |
| `link_iou` | **주 지표** — `IoU(prev_box, reacq_box)` |
| `linked` | `link_iou ≥ LINK_IOU` |
| `run_len` | 잃은 구간의 프레임 수 |
| `nearest` | 보조 — 재획득 프레임의 후보 중 `prev_box` 에 **가장 가까운 것**이 `reacq_box` 인가 |
| `reach` | 보조 — 중심 이동 거리 ÷ (상자 폭 × `run_len`). **프레임당 몇 상자폭 움직였나** |

### 🔴 외양 문턱을 새로 만들지 않는다

```
LINK_IOU = MIN_ANCHOR_IOU = 0.30
```

**production 에 이미 있는 값이다** — 입구가 사용자 상자와 검출을 「같은
사람」으로 묶을 때 쓰는 그 문턱이고, 5회차 구제도 같은 값을 썼다.
**이 회차가 만든 자유도는 0 이다.** (0.1·0.2·0.5 에서의 값도 함께 보고하되
**판정은 0.30 에서만** 한다.)

이 회차의 새 상수는 `SHORT_CAPS`·`MIN_RUNS` 둘, **표본 크기에 관한 것뿐**이고
어느 것도 「같은 사람인가」를 정하지 않는다.

## 표본 — 🔴 **이번엔 「안 쓴 표본」이 없다**

9회차가 층 B(과녁 밖 19구간)와 층 C(`O2GSaYqH8JY`)를 **이미 썼다.** 남은
미사용 클립은 없다(39건 중 33건이 `build_samples`, 나머지 6건 중 5건은 닻이
없다). **그 사실을 여기 적고 시작한다** — 나중에 「새 표본에서 확인했다」고
쓸 수 없다.

대신 갖고 있는 방어는 둘이다.

1. **층 일치는 그대로 본다** — 층 A 는 **커버리지 붕괴로 골라낸** 7건이고
   층 B 는 **안 무너진** 클립이다. 선택으로 생긴 현상이면 두 층이 갈린다
2. **묻는 양이 9회차와 다르다** — 그쪽은 외양(`app`), 여기는 **공간**(IoU)이다.
   순환은 「같은 클립」이 아니라 **「같은 값으로 세운 기준」**인데, 여기 문턱은
   production 에서 왔다

🔴 **그래도 이것은 약점이다.** 결론에 「표본이 소진된 상태에서 얻었다」를
같이 적는다.

| 층 | 무엇 | 9회차 상태 |
|---|---|---|
| **A** | 과녁 7건(`TARGET7`)의 재획득 구간 | 썼다 |
| **B** | 과녁 **밖** 클립의 재획득 구간 | 썼다 |
| **C** | `O2GSaYqH8JY` | 썼다 (거부 0건이라 이 회차엔 기여가 없을 수 있다) |

**대조군 관문은 9회차 그대로** 쓴다 — `clean_med ≥ TAU` **그리고** 깨끗 장수
`≥ MIN_CLEAN(20)`. 잘 따라갈 때도 안 닮는 클립에서는 「돌아왔다」 자체가
뜻을 못 갖는다.

## 🔴 판정 기준 — 결과를 보기 전에 고정한다

| | 기준 |
|---|---|
| **A** 자기 검사 | `chosen` 이 6회차 `track_gate` 와 **비트 동일** |
| **B** 표본 관문 | 관문 통과 클립에서, 주 층(사다리로 정한 상한)의 재획득 구간이 **`MIN_RUNS`(8) 이상**이고 **3개 이상의 클립**에서 나온다. 못 채우면 **판별불가** |
| **C** 층 일치 | 주 층에 **3구간 이상** 있는 층끼리 다수 쪽이 같아야 한다. 그런 층이 **둘 미만이면 확인 불가 → 판별불가** |
| **D** 🔴 계기 검사 | 주 층 안에서 \|Spearman ρ(`link_iou`, `run_len`)\| < **0.5**. 넘으면 8회차 결함 재발이라 **판정 무효** |
| **E** 결론 임계 | 다수 쪽이 주 층 구간의 **70% 이상** (8·9회차와 같은 폭) |

### 결론 셋

| | 조건 | 뜻 · 다음 회차 |
|---|---|---|
| **(ii) 대상은 거기 있었다** | `linked` **70%+** | 뿌리는 **닻 기술자**다. 다음은 더 강한 외양 표현이고, **새 의존을 부르는 처방 회차**다 |
| **(i) 대상이 없었다** | `linked` **30% 미만**(= 안 이어짐 70%+) | 🔴 **커버리지 붕괴는 결함이 아니다.** `None` 이 정직한 답이고 **추적 갈래를 닫는다**. 남는 일은 알리기와 화면 표기 |
| **(다) 판별불가** | 그 사이거나 · 층이 갈리거나 · B·D 가 안 서면 | 갈래를 **열어 둔다.** 어느 쪽으로도 안 적는다 |

🔴 **「섞여 있다」도 결과다.** 30~70% 사이면 두 사정이 함께 일어나는 것이고,
그때는 **처방을 하나로 못 고른다**는 것이 이 회차의 답이다.

## 🔴 하지 않는 것

- **`src/` 를 안 고친다.** 읽기만 한다 — 추적을 한 비트도 안 바꾼다
- **앞 회차 스크립트를 안 고친다.** import 만 한다
- **처방을 내지 않는다.** 산출물은 **갈래 판정 하나**다
- 🔴 **「사슬 잇기」를 판정에 안 쓴다.** 구간의 검출을 프레임마다 IoU 로 이어
  붙이면 거의 항상 이어진다 — **사람이 많으면 남을 거쳐서도 이어지기**
  때문이다(7회차: 잃은 프레임의 93%에 `auto[t]` 가 있었는데 닮은 것은 1%).
  「상자가 이어진다」는 「대상이다」가 아니다. 함께 보고에만 낸다
- 🔴 **커버리지를 성과로 읽지 않는다.** 같은 실수를 하루에 두 번 했다
  (18번 7회차 93%/1% · 37번 3회차 97%/46%)
- 🔴 **IoU 를 「대상인가」의 정답으로 승격하지 않는다.** 대리 지표다.
  말할 수 있는 것은 **「돌아온 자리가 잃은 자리인가」**까지다

## 함께 보고할 것 (판정에 쓰지 않는다)

1. **상한 사다리 전부** — 10·20·30·제한없음에서의 `linked` 비율과 구간 수
2. **문턱 민감도** — `LINK_IOU` 0.1·0.2·0.3·0.5 에서의 `linked` 비율
3. **`nearest`** — 길이에 덜 물드는 보조 지표(같은 프레임 안의 비교라 이동이
   상쇄된다). 주 지표와 방향이 갈리면 그것을 적는다
4. **`reach`** — 프레임당 상자폭 이동. 「사람이 갈 수 있는 거리인가」
5. **관문에 막힌 클립**에서의 같은 값 — 판정엔 안 쓰지만 방향은 본다
6. 재획득으로 **안 끝난** 구간의 수와 길이 — 이 회차가 못 보는 부분이다
