## 그래서 다음 회차는 외양이 아니다

세 회차 동안 외양으로 **하류를 기웠는데**, 원인은 그보다 **위**에 있었다.

| | |
|---|---|
| 시험할 것 | **이어가기에 한해** 임계 미달 검출도 후보로 받는다 — 단, 트랙과 **잘 겹칠 때만**(예: IoU가 통과 후보 최고보다 뚜렷이 높을 때) |
| 🔴 왜 이것이 값싼가 | **자동 경로를 안 건드린다.** `PERSON_ELIGIBLE_THRESHOLD` 는 그대로 두고 **지정 경로의 이어가기에서만** 예외를 둔다 → **기준 A(비트 동일)가 유지되고 B-6 재실행이 없다** |
| 🔴 위험 | 임계 미달은 **오검출도 많다.** IoU 조건을 느슨하게 잡으면 유령 박스를 따라간다. 그 문턱은 새 사전 등록으로 박는다 |
| 🔴 하지 말 것 | `PERSON_ELIGIBLE_THRESHOLD` **자체를 낮추지 말 것** — selector 동작 기준이라 B-1\~B-6 전부가 무효가 된다(로드맵 5절) |
