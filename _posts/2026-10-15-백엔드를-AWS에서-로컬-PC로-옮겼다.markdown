발표 준비 중에 "다른 사람이 구글 로그인을 누르면 안 들어가진다"는 문제가 있었습니다.

## 원인

처음엔 구글 OAuth 동의 화면이 「테스트 중」이라 등록된 계정만 들어가는 것으로
봤는데, **틀렸습니다** — 이미 게시돼 있었습니다(정어진 확인). 실제 원인은
**AWS 크레딧이 떨어져 백엔드가 멈춘 것**이었습니다. 웹 화면은 Vercel에서 나오지만
로그인 요청이 부르는 백엔드가 응답하지 않아(Cloudflare 522) 구글·비밀번호·
심사위원 로그인이 **모두** 「알 수 없는 오류」였습니다.

## 결정 — 로컬 PC를 24시간 서버로

AWS는 이번 달이 지나면 쓸 수 없어서, 다시 살리는 대신 **박민호 PC(WSL)로 옮겼습니다.**

- PostgreSQL(pgvector) 컨테이너와 FastAPI 백엔드를 이 PC에서 상시 서비스로 띄움
  (재부팅 뒤 자동 시작)
- Cloudflare 터널로 기존 API 주소를 이 PC로 연결 — **Vercel은 재배포 없이 그대로**
- 사이트에서 로그인 요청이 200으로 성공하는 것까지 확인

## 아직 안 된 것

- **데이터**: 빈 DB로 시작했습니다. AWS DB 덤프를 이번 달 안에 받아야 합니다
- **영상 업로드·분석**: S3와 AWS GPU 워커에 기대고 있어서 지금은 안 됩니다
- **24시간 유지**: 이 PC가 꺼지거나 잠들면 사이트 로그인이 다시 안 됩니다

누가 무엇을 할지는 [미결 항목 `min` 30번](/pending/)에 있습니다.
