# 정상호 님께 — 세 가지를 여쭙습니다

백엔드가 EC2에서 돌기 시작했고 스키마가 실물 DB에 다 올라갔습니다. **분석 결과를
받을 자리가 실제로 생겼습니다.** 그래서 미뤄 둔 결정 하나가 이제 진행을 막습니다.

**정본은 미결 항목입니다.** 이 글은 알림이고, 각 항목에 담당·기한·확인 명령이
붙어 있습니다.

## 이 글을 Claude에게 주실 때

```
jekyll/pages/pending.markdown 에서 '담당.*정상호' 를 찾아 나에게 온 항목을 읽어줘.
특히 jin 구역 1번(적재 규격)은 fastapi/docs/api-contract.md 3-1절에 선택지 A·B·C가
대가와 함께 적혀 있으니 그걸 읽고, agent/rubrics/ 의 실물과 대조해서
어느 안이 맞는지 판단할 근거를 정리해줘. 결정은 내가 한다.
```

## ⑴ 🔴 분석 결과 적재 규격 — 이것이 지금 제일 앞을 막습니다

`agent/`가 만든 분석 결과를 DB에 넣으려면 `metric_definition`(지표 정의)이 먼저
채워져야 하는데, **지금 스키마로는 채울 수가 없습니다.**

루브릭 11개 지표 중 **5개가 종목을 넘나듭니다.** `trunk_forward_lean_deg_at_impact`는
축구·야구·농구에 전부 쓰이는데, `metric_definition.code`가 기본키라 같은 코드를 두
종목으로 정의할 수 없습니다(실제로 넣어 보고 `UniqueViolation`을 확인했습니다).

- 선택지 **A·B·C**와 각각의 대가: `fastapi/docs/api-contract.md` **3-1절**
- 제 제안은 **A**(`metric_definition`에서 `sport_code` 제거)입니다. 지표는 종목이
  달라도 **같은 물리량**이라, 나누면 종목 간 비교가 불가능해집니다
- 반대로 `position`은 나누는 것이 맞습니다 — 축구의 `FW`와 농구의 `FW`는 다른 것이라
  `(sport_code, code)`에 유일 제약을 걸었습니다. **두 설계가 반대 방향인 것이 핵심**입니다

부록 D.3을 건드리는 결정이라 제가 혼자 정하지 않았습니다. **합의 전에는 적재
엔드포인트를 만들지 않습니다** — 지금은 스키마와 규격 초안까지만 올라가 있습니다.

```bash
grep -rn analyses fastapi/app/     # 결과 없음 = 아직 구현 안 함 (정상)
```

## ⑵ 미결 9번의 담당 표기가 저(정어진)로 되어 있습니다

`ho` 구역 9번(4K 입력에서 host RAM이 먼저 터진다)의 `담당`이 정어진인데, D-1 구현은
정상호 님이 `agent/pose.py`에서 하셨고 남은 몫(`max_frames`·4K 상한)도 `agent/`
안입니다. 10~12번은 전부 `담당: 정상호`입니다.

착오라면 그쪽 구역이라 **제가 고치지 않았습니다.** 제가 맡아야 하는 것이면 알려
주세요 — 영상 수집·전처리가 제 영역이라 그 뜻이었다면 납득이 갑니다.

## ⑶ `agent/`에 진입점 문서가 없습니다

`fastapi/`와 `www/`에는 `CLAUDE.md`가 있어서 그 폴더에서 작업할 때 관례가 자동으로
읽힙니다. `agent/`에는 없습니다.

루트 `CLAUDE.md`는 모두가 읽으니 요청이 아주 안 닿는 것은 아닙니다. 다만 **그
폴더에서만 통하는 것**(테스트 구조, 지우면 안 되는 검사, 모델 버전 고정 같은 것)을
알려 줄 자리가 없습니다.

```bash
ls agent/CLAUDE.md agent/AGENTS.md     # 지금은 둘 다 없습니다
```

🔴 **루트 `CLAUDE.md` 내용을 복사하지는 말아 주세요** — 사본은 한쪽만 고쳐집니다.
그 폴더에서만 통하는 것과 포인터만 있으면 됩니다. `fastapi/CLAUDE.md`가 참고용
예시이고 규격은 아닙니다.

## 곁들여 — 백엔드 쪽 상황

- **EC2에서 돕니다.** PostgreSQL 18에 스키마 20개 테이블이 올라갔고, `sport` 3행
  (`football`·`baseball`·`basketball`)과 `position` 11행이 들어갔습니다
- 밖에서는 아직 안 보입니다(포트 미개방). 지금은 SSH 터널로 확인합니다
- 오늘 API가 늘었습니다 — 카드 생성, 팀 생성·가입·탈퇴, 경기 등록·목록,
  지원·제안. 계약은 `fastapi/docs/api-contract.md` 3장~3-5절입니다

**⑴이 정해지면 `metric_definition` 수정과 시드가 제 첫 작업입니다.** 그다음이
`player_vector`(벡터 차원 수도 거기에 걸려 있습니다).
