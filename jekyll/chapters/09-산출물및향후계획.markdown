### 단기 (MVP 출시 ~ 3개월)
- 용병 매칭 핵심 기능 안정화
- 실력분석 기초 알고리즘 적용
- 특정 지역/커뮤니티 대상 시범 운영

### 중기 (3~6개월)
- 실력분석 고도화 (데이터 누적 기반 정교화, [TBD — ML 적용 검토])
- 정산/결제 기능 정식 도입
- 종목 확대 검토 (축구·야구 외 추가 종목)

### 장기 (6개월~)
- 전국 단위 서비스 확장
- 데이터 기반 부가 서비스(랭킹, 리그 운영 지원 등)
- 스포츠 브랜드/구장 업체 제휴 확대
