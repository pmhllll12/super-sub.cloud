# 부록 A. 용어 정의

| 용어 | 정의 |
|---|---|
| 용병 | 팀 소속이 아니지만 특정 경기에 한해 참여하는 대체 선수 |
| 매칭 | 팀의 용병 모집 공고와 지원자를 연결하는 과정 |
| 실력분석 | 경기 참여 이력 및 상호 평가 데이터를 기반으로 산출한 개인의 실력 지표 |
| 상호 평가 | 경기 종료 후 팀원/상대팀이 참여자에 대해 남기는 평가 |
| 노쇼(No-show) | 매칭이 확정되었으나 경기에 참여하지 않는 행위 |
| 신뢰도 점수 | 후기, 노쇼 이력 등을 종합해 산출하는 사용자 신뢰 지표 |
| MVP | Minimum Viable Product, 최소 기능 제품 |
| BI | Brand Identity, 브랜드 아이덴티티 |
