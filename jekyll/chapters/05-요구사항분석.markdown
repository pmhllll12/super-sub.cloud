# 05. 요구사항 분석

## 사용자 정의
| 사용자 유형 | 설명 |
|---|---|
| 팀 관리자 | 팀을 대표해 용병 모집 공고를 등록/관리 |
| 용병(개인 사용자) | 경기를 탐색하고 지원, 실력분석 리포트를 확인 |
| 운영자(Admin) | 신고 처리, 콘텐츠 관리, 데이터 모니터링 |

## 기능적 요구사항 (Functional Requirements)

### 회원/프로필
- FR-01 회원가입/로그인 (이메일, 소셜 로그인)
- FR-02 프로필 등록(포지션, 종목, 경력, 사진)
- FR-03 실력분석 리포트 조회

### 매칭
- FR-04 팀의 용병 모집 공고 등록 (일시/장소/포지션/인원/참가비)
- FR-05 공고 검색 및 필터링(종목, 지역, 날짜, 포지션)
- FR-06 지원 및 매칭 확정
- FR-07 매칭 알림(푸시/메시지)

### 실력분석
- FR-08 경기 후 상호 평가 입력
- FR-09 평가 데이터 기반 실력 등급/리포트 자동 생성
- FR-10 실력 변화 추이 시각화

### 커뮤니티/신뢰도
- FR-11 후기 작성 및 조회
- FR-12 노쇼/매너 신고 및 페널티 처리
- FR-13 정산(참가비 결제) [TBD — 결제 연동 범위]

| 확장성 | 사용자 증가 시 수평 확장 가능한 인프라 구조 |

## 우선순위 (MVP 기준)
1. 회원/프로필, 용병 모집·매칭 (Must have)
2. 상호 평가 및 실력분석 기본 버전 (Must have)
3. 정산/결제, 랭킹, 고급 통계 (Should/Could have)
