# 부록 E. 결정 기록

프로젝트를 진행하며 **실제로 채택한 결정**, 그렇게 정한 **이유**, 함께 검토했으나
**채택하지 않은 대안과 그 이유**, 그리고 **언제 정해졌는지**를 한자리에 모은다.

> **정본은 개발 로그(`/devlog/`)와 미결 항목(`/pending/`)이다.** 이 페이지는 사람이
> 훑어보도록 결정과 근거만 추린 것이고, 세부 수치·검증 과정·구현 위치는 링크한
> 원문에 있다. 결정이 바뀌면 원문을 고치고 이 표를 따라 갱신한다.

**읽는 법.** 「대안 / 기각」이 있는 항목은 다른 길을 실제로 재보고 접었다는 뜻이다.
「되돌림」·「보류」로 표시된 것도 결정이다 — 왜 그 길로 가지 않는지가 기록으로 남아야
같은 조사를 반복하지 않는다.

### 1) 측정과 판단의 분리
- **채택** — 영상을 언어 모델에 직접 넣어 점수를 매기게 하지 않는다. 관절 각도·각속도
  같은 수치는 결정론적 포즈 추정 코드가 산출하고, 언어 모델은 그 수치를 채점 기준과
  대조해 **판정만** 한다. 총점 계산은 애플리케이션 코드가 한다.
- **이유** — 언어 모델은 픽셀에서 각도를 측정할 수 없다. 측정하지 않은 값을 그럴듯하게
  지어내고 같은 영상에서 다른 점수가 나온다. 근거를 댈 수 없는 점수는 실력 검증
  산출물이 될 수 없다. 데이터 모델도 측정값과 리포트를 별도 테이블로 나눠 이 구조를

- **대안 / 기각**

## 3. 인프라·배포

### 26) 배포는 AWS EC2 단일 인스턴스, DB는 같은 인스턴스에 병설
- **채택** — 백엔드를 AWS EC2(t3.large, 서울 리전)에서 서비스로 상시 구동하고,
  PostgreSQL 18을 **같은 인스턴스**에 설치한다. 디스크는 8GB → 30GB로 증설. Python
  3.14는 OS 저장소에 없어 uv로 독립 실행형을 받아 `/opt`에 둔다(홈 디렉터리 권한
  때문에 서비스 계정이 못 읽는다).
- **대안 / 기각** — 관리형 DB(RDS). 비용이 걸린 결정이라 같은 인스턴스로 시작하되,
  나중에 옮기더라도 연결 문자열 하나만 바뀐다.

### 27) 고정 IP 미부착, 외부 공개는 결정하는 날 한꺼번에
- **채택** — 탄력적 IP를 붙이지 않는다. 백엔드 주소·DNS·포트 개방·nginx 리버스
  프록시·Let's Encrypt TLS는 **외부 공개를 결정하는 날** 그날의 IP로 한꺼번에 한다.
  웹은 Vercel에 두고 API만 EC2를 가리킨다. 그 전까지 개발·시연은 SSH 터널.
- **이유** — 탄력적 IP는 비용 대비 필요가 아직 없고, 인스턴스를 자주 껐다 켜므로
  지금 DNS를 걸면 곧 어긋난다. 설정이 빈 채로 포트만 열면 서비스가 막히는 게 아니라
  잘못 도는 상태로 노출된다.

### 28) GPU 인스턴스(g4dn.xlarge)는 쓸 때만 켠다 + 자동 종료
- **채택** — GPU 검증용 g4dn.xlarge(Tesla T4)는 방치하지 않고 쓸 때만 켠다. 유휴
  시간 기준의 자동 종료 스크립트를 분석보다 먼저 깔았고, 종료 동작이 "중지"(삭제
  아님)인 것을 먼저 확인했다. 모델 가중치는 S3가 아니라 HuggingFace에서 받은 로컬본을
  쓴다(쓰기 권한 없음). 인스턴스는 원본 영상을 읽기만 한다.
- **이유** — 방치 시 월 $490, 하루 2시간이면 월 $53로 9배 차이. 끄는 걸 잊는 것이 이
  배포의 가장 큰 비용 위험. GPU 할당량이 계정 기본 0이라 증액 신청했다(작은 인스턴스
  하나에 묶이지 않도록 넉넉히).
