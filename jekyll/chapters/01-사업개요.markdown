## 비전
"경기에 사람이 부족해서 취소되는 일이 없는 스포츠 생활"을 만든다.

## 미션
- 동호회/팀이 부족한 포지션의 용병을 빠르고 신뢰도 높게 구할 수 있도록 연결한다.
- 축적된 경기 데이터를 기반으로 개인의 실력을 객관적으로 분석·시각화하여, 매칭의 신뢰도를 높인다.

## 핵심 가치 (Core Value)
| 가치 | 설명 |
|---|---|
| 신속성 | 급하게 필요한 용병을 짧은 시간 안에 구인 |
| 신뢰성 | 후기·실력분석 데이터 기반의 매칭으로 "아무나 오는" 문제 해결 |
| 성장 | 경기 데이터 누적을 통한 개인 실력 성장 추적 |
